# Objectives

Attack the rung 3 site with crafted course content, then watch rung 6 stop each attack. Finish by exploring
the security tests in tutors-mono-repo that do the same job at full scale.

By the end of this lab you will have:

- built a hostile course with rung 3 and run its script in your browser by clicking a link
- made rung 3 publish a file from outside the course folder through a symbolic link
- built the same course with rung 6 and seen every attack neutralised, with warnings that say why
- watched the Content Security Policy block script you injected by hand
- built a private course, been refused, and built it on purpose
- broken one defence and read the Teaching Failure that caught it
- run and read upstream's security tests

Allow about ninety minutes. Work in a scratch folder; nothing here should be committed.
