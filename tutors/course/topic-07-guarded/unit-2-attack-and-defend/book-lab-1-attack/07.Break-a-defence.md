# Break a defence

Ask yourself, or your agent, to "simplify markdown.ts". Suppose it takes out the sanitiser. Make that change
by hand in `packages/lite/src/markdown.ts`:

~~~ts
// before
const safe = safeUrl(url!, bang ? "image" : "link");
// after
const safe: string | null = url!;
~~~

Run the gate:

~~~bash
pnpm test 2>&1 | grep -A2 "XSS corpus:" | head -12
~~~

~~~
XSS corpus: "javascript:alert(1)" (the classic: runs on click) reached the page as href="javascript:alert(1" opens as javascript:.
...
Course text must be escaped (html`` in packages/lite/src/html.ts) and every course URL must pass safeUrl (packages/lite/src/url.ts) before it reaches an href or src.
~~~

Count the red tests. The table-driven corpus fails once per payload; the property test fails on a generated
URL such as `"\u001fFilE:alert(1)"`, with its seed so you can replay it. The CLI test on the hostile course
fails too. Undo the change and run `pnpm test` until it is green.
