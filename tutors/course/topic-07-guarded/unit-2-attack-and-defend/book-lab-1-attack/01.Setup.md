# Setup

You need the `AI-Reference-Projects` clone from Lab 01, Node.js 22.18 or later and pnpm. Install both
variants you will compare:

~~~bash
cd AI-Reference-Projects/tutors/variants
(cd rung-3-layers && pnpm install && pnpm test)
(cd rung-6-guarded && pnpm install && pnpm test)
~~~

Both gates end green. Rung 6's summary reads something like:

~~~
# tests 209
# pass 209
# fail 0
~~~

Make a scratch folder for the sites you will build, and remember where it is:

~~~bash
export LAB=$(mktemp -d)
echo $LAB
~~~

## The hostile course

Open `rung-6-guarded/tests/fixtures/hostile-course/` and read every `.md`, `.marp` and `weburl` file. It is a
valid Tutors course whose author wants to run script in your readers' browsers. List, for each file, what it
tries. You should find at least: `javascript:` links in three disguises, a `data:` SVG image, raw `<script>`,
`<img onerror>`, `<svg onload>` and `<iframe>` tags, a web link whose address is script, and two links that
leave their folder.
