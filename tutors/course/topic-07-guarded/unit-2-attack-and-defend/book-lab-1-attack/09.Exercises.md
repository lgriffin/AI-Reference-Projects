# Exercises

## Exercise 1: a payload of your own

Find a payload in the [OWASP XSS Filter Evasion Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/XSS_Filter_Evasion_Cheat_Sheet.html)
that is not in `packages/lite/tests/xss-corpus.test.ts`. Add it to `HOSTILE_URLS` or `HOSTILE_TEXT` with a
reason. Does it pass? If it fails, you found a bug: fix `url.ts`, not the test.

## Exercise 2: a stricter image rule

Rung 6 lets images load from any `https:` host. Should a course image load only from the course's own site?
Change `img-src` in `CSP` and `ALLOWED.image` in `url.ts` together, and update the tests. What breaks for a
course that shows a diagram from a CDN? Who should decide?

## Exercise 3: a third adapter

Write a `ZipFileSystem` that implements `FileSystemPort` over an in-memory map of a zip's entries (you can
fake the zip as a `Record<string, string>` with `../` names in it). Run the gate before you add it to the
contract test: which rule fails first? Then make it pass the containment cases.

## Exercise 4: compare the policies

Put `canView` in `packages/rbac/src/index.ts` beside upstream's `turnsAway` in
`packages/svelte/connect/src/services/connect.svelte.ts`. Write down one behaviour that differs, if any, and
say which you would keep.
