# The brief

Work in a copy of the variant, so the original stays a reference:

~~~bash
cd AI-Reference-Projects/tutors/variants
cp -r rung-6-guarded my-rung-6 && cd my-rung-6
pnpm install
pnpm test:assignment      # 31 tests, all red: nothing is written yet
~~~

## Part A: raw HTML in Markdown

Add `packages/gen/src/raw-html.ts`, exporting `rawHtmlFindings(markdown: string): string[]` from
`@ladder/gen`. It returns the lower-case names of the **HTML elements** written as raw tags in the Markdown,
each once, in order of first appearance. Code is not raw HTML: leave out fenced blocks and inline code spans,
as `pageSources` in `packages/gen/src/portable.ts` already does. Text that only looks like a tag is not raw
HTML either: `a < b`, `Array<string>`, `Map<K, V>`, `->`, and an autolink such as `<hello@tutors.dev>`.

Then make `buildCourse` call it for every `.md` and `.marp` file it reads, in every folder (the course,
units and sides too), and pass one warning per file and tag to `options.warn`:

~~~
raw-html topic-1/note-1/note.md: <iframe> is raw HTML. ...
~~~

The text after the colon is yours: say what rung 6 does with it, what the Summit reader does with it, and
what the author should do instead.

## Part B: locked content

Add two functions to `packages/rbac/src/index.ts`:

- `isLoRouteLocked(route: string, locks: ReadonlyMap<string, boolean>): boolean`, mirroring upstream's
  function of the same name in `packages/svelte/utils/rbac/src/rbac-service.svelte.ts`;
- `canSeeLo(role: Role, route: string, locks: ReadonlyMap<string, boolean>): boolean`: educators see
  everything; everyone else sees what is not locked.

`@ladder/rbac` must stay pure: the Purity rule in `tests/architecture/architecture.test.ts` still applies.

## Finish

When `pnpm test:assignment` is green, delete the `skip` from both `describe` blocks in
`tests/assignment/guarded.assignment.test.ts` (or set `LADDER_ASSIGNMENT=1` in the `test` script) so the
Single Gate runs it, and run `pnpm test`.
