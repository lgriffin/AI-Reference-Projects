# Raw HTML and locked content

Two small security features for rung 6, each mirroring something real in tutors-mono-repo:

- **Part A, content safety:** a rule in gen that warns when a course's Markdown holds raw HTML, such as an
  `<iframe>` or a `<script>`, outside code. Rung 6 shows raw HTML as text; upstream's reader sanitises it
  away. Either way the author is surprised, so tell them at build time, as upstream's V016 does for slides.
- **Part B, authorisation:** content locks. Upstream educators can lock a topic or unit so students do not
  see it (`guides/RBAC.md`, "Content Locking"). Add the pure policy for it to `@ladder/rbac`.

A grading test is already in the variant, skipped until you start. You may work with a coding agent; the
Rung Fence and the architecture rules still hold, and every line is yours to explain.
