# Acceptance criteria

Written as EARS sentences, one "shall" each.

| Id | Criterion |
| --- | --- |
| AC1 | The generator package shall export `rawHtmlFindings(markdown)`. |
| AC2 | When Markdown prose holds a raw tag that names an HTML element, `rawHtmlFindings` shall return that element's lower-case name, once, in order of first appearance. |
| AC3 | While text is inside a fenced block or an inline code span, or only resembles a tag (a comparison, a generic type, an arrow, an autolink), `rawHtmlFindings` shall not report it. |
| AC4 | When `buildCourse` reads a Markdown or Marp file holding raw HTML, the generator shall warn once per file and element, with a message that starts `raw-html <path>:` and names the element in angle brackets. |
| AC5 | When a learning object's route, or one of its ancestors' routes, is locked, `isLoRouteLocked` shall return true; a lock on a course id alone shall lock nothing, an unlocked entry shall lock nothing, and trailing slashes shall be ignored. |
| AC6 | `isLoRouteLocked` shall take time linear in the length of the route, however many slashes it ends with. |
| AC7 | If the role is not `educator`, then `canSeeLo` shall return false for a locked route; for an educator it shall return true. |
| AC8 | The rbac package shall stay pure: the architecture tests shall pass with the assignment's code in place. |
| AC9 | The Single Gate (`pnpm test`) shall run the grading test and pass. |

AC1 to AC7 are checked by `tests/assignment/guarded.assignment.test.ts`. AC8 and AC9 are checked by
`pnpm test` once you have removed the skip.

## The cases the grading test uses

Part A's corpus holds eleven raw-HTML inputs (`<iframe>`, `<script>`, `<object>`, `<embed>`, `<form>` with
an `<input>`, `<svg/onload>`, `<img onerror>`, `<style>`, a raw `<a href="javascript:...">`, `<meta
http-equiv="refresh">`, an upper-case `<IFRAME>`) and seven look-alikes that must not be reported. Part B's
table is upstream's: `guides/RBAC.md` ("Descendant Route Filtering") and `tests/unit/rbac/lock-matching.test.ts`.
