# The brief

Work in `tutors/variants/rung-5-proven`. Commit after each numbered step, with the gate green where it can
be.

1. **The sentence.** Take the next id with `pnpm test:ears:audit --next-id`. Write the requirement in
   `REQUIREMENTS.md`: it is triggered by what `properties.yaml` lists, it is about the generator, and the
   course keeps the topic. Show the sentence to a person (a peer, or your tutor) before you go on.
2. **The scenario.** Add the `Rule:` to `tests/bdd/features/generator/course-folder.feature`, word for
   word, with its id and EARS tag, and at least one scenario. Bind it in
   `tests/bdd/steps/generator/course-folder.steps.ts`. See it fail.
3. **The model.** A topic may now carry `hide`. Add it to `Topic` in `packages/model/src/index.ts` as an
   optional boolean.
4. **The implementation.** In `packages/gen`, read `properties.yaml` through the `FileSystemPort` (never
   `node:fs`: the Port rule) and set `hide: true` on each topic the `ignore` list names. Read only the block
   list form upstream's corpus uses:

   ~~~yaml
   ignore:
     - topic-09-hidden
   ~~~

   There is no YAML library on this rung, and the Rung Fence will refuse one. A small function that reads
   this one key is enough.
5. **A property.** Add a file to `tests/fuzz/` whose test titles cite your id: for any set of topics and
   any subset of them listed under `ignore`, exactly that subset is hidden and no topic is left out. Give
   it a "... can fail" test against a broken generator.
6. **The mutation score.** Run `pnpm test:mutation` and `pnpm check:mutation-floors`. Kill survivors with
   unit tests in `tests/unit/gen/` until every floor holds. Raise a stale floor with `--update`; never lower
   one.

## Going further (not graded)

- A second requirement for the site: "If a topic is hidden, then the site shall ..." What should it do,
  and what does upstream's reader do? Write the sentence before the code.
- The `package-api` contract will fail if you export a new function from `@ladder/gen`. Decide whether
  your parser should be exported, and say why in your commit message.
