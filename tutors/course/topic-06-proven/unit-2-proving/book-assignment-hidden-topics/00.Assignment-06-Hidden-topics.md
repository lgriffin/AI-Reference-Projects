# Hidden topics

A lecturer can hide a topic without deleting it: `properties.yaml` lists it under `ignore`, and upstream's
generator writes the topic with `hide: true`, so the reader can leave it out of the course page while its
links keep working. Upstream states this as Rule 0266 in
`tests/bdd/features/generator/course-json.feature`.

Your task is to bring that rule to rung 5, end to end, the way this topic taught: an EARS requirement, a
scenario, the implementation in the right layer, a property test that can fail, and every mutation floor
held. The code is about twenty lines. The proof is the work.

You may work with a coding agent. The requirement is yours to write and approve before any code is.
