# Install and run

## Install

~~~bash
cd AI-Reference-Projects/tutors/variants/rung-5-proven
pnpm install
~~~

pnpm prints one warning, `Failed to create bin ... vitest-cucumber`. The package ships without its
command-line tool; the library you use is complete. `RUNG.md` says so too.

## The gate

~~~bash
pnpm test
~~~

Expected, at the end:

~~~
 Test Files  24 passed | 1 skipped (25)
      Tests  183 passed | 6 skipped (189)
~~~

The skipped file is the assignment's grading test. It waits for `LADDER_ASSIGNMENT=1`.

## The tiers, one at a time

~~~bash
pnpm test:bdd           # 3 feature files, 12 Rules, 19 scenarios
pnpm test:ears:audit    # EARS audit: every requirement is proved, and every citation is known.
pnpm test:fuzz          # the properties at 1000 runs each
~~~

Open `tests/TESTING.md` beside the folder list. Every folder under `tests/` has a row, and
`tests/architecture/test-tiers.test.ts` fails if one does not.
