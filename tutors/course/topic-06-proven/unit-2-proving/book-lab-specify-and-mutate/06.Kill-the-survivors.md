## Read the survivors

Open `reports/mutation/index.html` and choose `site-builder.ts`. All five survivors are on your new line:

| Mutant | What it does |
| --- | --- |
| `lab.los.length > 1` to `true` | a one-step lab says "Step 1 of 1" |
| `lab.los.length > 1` to `lab.los.length >= 1` | the same |
| `lab.los.length > 1` to `false` | no step page ever says where it is |
| `lab.los.length > 1` to `lab.los.length <= 1` | only one-step labs do |
| `index + 1` to `index - 1` | "Step 0 of 3" |

The third and fifth break R-013 outright, and your scenario checks R-013. Why did they survive?

## Why the scenario cannot kill them

Read the header of `vitest.config.mutation.ts`. The mutation run does not include the BDD steps.
vitest-cucumber makes every Given, When and Then a test of its own, and Stryker reruns only the tests that
ran the mutated line. Your When step builds the site; your Then step checks it. Stryker would rerun the When
alone, and nothing would be checked. `RUNG.md` has the numbers from the runs that found this.

So the scenario proves the rule, and a unit test pins the code.

## Write the unit test

Append to `tests/unit/lite/site-builder.test.ts`:

~~~ts
test("R-013: each step page of a lab of several steps says where it is; a lab of one step does not", () => {
  const labOf = (...names: string[]): Course => ({
    type: "course", id: "c", title: "C", summary: "", contentMd: "# C", route: "/",
    los: [{ type: "lab", id: "l", title: "L", summary: "", contentMd: "", route: "", los: names.map((name) => ({ type: "step" as const, id: name, shortTitle: name, title: name, contentMd: "", route: "" })) }],
  });
  const pages = buildSite(labOf("One", "Two", "Three"));
  assert.match(pages.find((p) => p.path === "l/Two.html")!.html, /<p class="position">Step 2 of 3<\/p>/);
  assert.doesNotMatch(buildSite(labOf("Only"))[0]!.html, /class="position"/);
});
~~~

The title cites `R-013`, so the closure check knows it too. Run `pnpm test`, then Stryker again:

## The trap

`buildSite(labOf("Only"))[0]` is the first page of the site: the **course** page, which never had a
position. The assertion was true for the wrong reason. Look for the lab's own page instead:

~~~ts
  assert.doesNotMatch(buildSite(labOf("Only")).find((p) => p.path === "l/index.html")!.html, /class="position"/);
~~~

~~~
   site-builder.ts       |  93.55 |  100.00 |       58 |         0 |          0 |        4 |
...
Every file holds its floor.
~~~

The four "no cov" mutants are the `default:` branches that only a type error could reach.

Mutation testing found a test that could not fail. That is what it is for.
