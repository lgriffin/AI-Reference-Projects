# Kaizen (Evaluate)

Every lab has ended here. This week the whole lab was Kaizen upstream, so this step turns the question round:
improve the way **you** contribute. Twenty minutes, in your notes. It feeds the A3 in the capstone.

## 1. The value stream, as it really went

Take the sketch from step 3 and write the real times beside your estimates. Where did the lead time go? Which
of your three "I will ... so that ..." sentences held, and which did not?

## 2. Name one waste

| Waste | What it may have looked like this week |
| --- | --- |
| Rework | CI failed on something a local check would have caught; the agent's diff had to be cut back |
| Waiting | a pull request open with no reply; a long `pnpm install` |
| Extra features | a path in `git diff --stat` that was not on "May touch" |
| Relearning | looking up the id format or the branch naming a second time |
| Handoffs | a reviewer asking a question your description should have answered |
| Task switching | two runtimes, two Node versions, two repositories |

## 3. Find its root cause

Use Five Whys, as in week 5. Stop when you reach something you could change. Do not stop at "I forgot" or
"the agent did it": ask why nothing reminded you, or why the manifest allowed it.

## 4. Improve the standard work

Make one change to **your** standard work, and propose one to somebody else's.

- **Yours**: your session manifest template, your shell profile, your checklist before pushing. Make the
  change now.
- **The ladder's**: one sentence that should change in a variant's `AGENTS.md`, or in a lab of this module.
  Write it as an issue for the module.
- **Upstream's**: one thing a first-time contributor has to know that no document or check states. Write the
  sentence that would put it at L2 and say where it belongs. CONTRIBUTING.md asks for exactly this: "If any
  step of this did not work as written, that is a bug in this document."

## 5. Look back over the twelve weeks

Read your eleven earlier Kaizen notes in order. Which improvement is still in use? Which waste came back?
Write three lines on what you would tell a student starting week 1, and bring them to the final class.

Kaizen has no last step. The next contributor starts from the standard work you leave behind.
