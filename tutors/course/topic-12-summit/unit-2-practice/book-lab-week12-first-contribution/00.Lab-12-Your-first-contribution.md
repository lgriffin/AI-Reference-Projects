# Objectives

Make one small, real improvement to tutors-sdk/tutors-mono-repo with a coding agent, under the ladder. You
will set rung 7's standard version beside the real repository, sketch the value stream of an upstream pull
request, choose an improvement at a rung you have finished, specify it first in upstream's own style, fence
your agent with a session manifest, run the repository's gates, and open a pull request a maintainer can
review in one sitting.

## Learning outcomes

| Outcome | Level | Steps | Module outcome |
| --- | --- | --- | --- |
| Map each rung to the upstream areas it mirrors, and classify what upstream adds beyond rung 7 | Analyse | 2 | M1, M4 |
| Judge at which Assertion Ladder level upstream keeps a rule, citing the file | Evaluate | 2, 8, 11 | M5, M7 |
| Choose a small improvement by its value, at a rung you have finished, and find its root cause | Evaluate | 3, 4 | M8 |
| Specify the improvement first as an EARS Rule and scenario in upstream's style, and fence your agent | Create | 5, 6 | M2, M6 |
| Implement the improvement, run the gates and defend it in a pull request | Create | 7, 8, 9 | M3, M8 |

Each step's heading names its Bloom level. The last two steps are Build beyond (Create) and Kaizen
(Evaluate). The week's Lean focus is Kaizen upstream: one small improvement to someone else's standard work.

## You need

- your `~/src/tutors-ladder` from earlier weeks, and rung 7's standard version from week 11;
- your clone of tutors-mono-repo (`$MONO`, from week 1) and a GitHub account;
- **Node 26.13.0 or later** and pnpm 11.24.0 for the mono-repo. The variants ran on Node 22.18. Upstream's
  `package.json` (`engines`) is the source of truth and `.nvmrc` pins the version CI uses;
- for the full test suite, `kubectl` or `kustomize` on your `PATH` (three platform conformance tests need one).

Allow three to four hours, spread over the week. Waiting for a reply or a review is part of the work; step 3
is about exactly that.

The work is yours. The agent helps; the fence keeps its help at your level; the gates and the reviewer decide.
This lab is also the first half of the capstone, assignment A8.
