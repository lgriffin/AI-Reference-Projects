# Build and run

From the course repository:

~~~bash
cd tutors/variants/rung-4-reader
pnpm install
pnpm test
~~~

`pnpm test` is the Single Gate. It runs, in order: `tsc` for each package, `svelte-check` for the reader,
every `node --test` suite, then `pnpm build`. Near the end you should see:

~~~
COMPLETED ... FILES 0 ERRORS 0 WARNINGS 0 FILES_WITH_PROBLEMS
# tests 230
# pass 227
# fail 0
# skipped 3
...
> Using @sveltejs/adapter-static
Wrote site to "build"
~~~

The three skipped tests grade the assignment in this unit; they run only with `pnpm test:assignment`. The
number of tests can grow as the variant does; what matters is `# fail 0` and the build line.

## The smoke test

~~~bash
pnpm test:e2e
~~~

This builds the reader, serves `apps/reader/build` on a small file server and drives Chromium from the home
page to a lab step. Expect `# pass 3`. If Playwright says no browser is installed, run
`pnpm exec playwright install chromium` once.

## Run it

~~~bash
pnpm dev
~~~

Open <http://localhost:5173/>, press **Open the course**, and click through to a lab. Use the left and right
arrow keys on a lab step.
