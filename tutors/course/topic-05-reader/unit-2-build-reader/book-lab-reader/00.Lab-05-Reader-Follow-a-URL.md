# Objectives

Build and run the rung 4 reader, follow one URL through its code from the route folder to the card you
click, then run the real Tutors reader and find the same flow there.

By the end you will have:

- passed the reader's Single Gate and its browser smoke test;
- seen `tutors.json` cross from the generator to the reader, and nothing else cross;
- traced a topic page and a lab step through about a dozen files;
- watched a rune warning, a layering rule and the Raw HTML rule fail with their teaching messages;
- opened the same route, service, tree and card files in tutors-mono-repo at `2b96b69`.

You need Node 22.18 or later and pnpm for the variant, and Node 26.13 or later for the upstream reader
(step 7). Allow about two hours.
