## Run it

The mono-repo needs Node 26.13 or later and pnpm 11.24 or later (`package.json` `engines`, `.nvmrc`). From
the mono-repo root, as `apps/reader/README.md` says:

~~~bash
pnpm install
cp .env.example .env
pnpm dev
~~~

`pnpm dev` builds `ui-primitives`, `ui-navigators` and `ui-components` first, then serves the reader. Open
<http://localhost:5173/course/reference-course> with the Network tab open: one request for
`https://reference-course.netlify.app/tutors.json`.
