# Exercises

1. **A video kind.** Upstream has a `/video/[courseid]/[...loid]` route. Without adding a kind to the model,
   sketch which rung 4 files would change and which rule or check would guide each change.
2. **Breadcrumbs for units.** `breadCrumbs` skips units because a unit has no page. Make a unit crumb link
   to its box on the topic page (`Units.svelte` gives each box `id={unit.id}`). Add a test to
   `apps/reader/tests/lo-tree.test.ts` first.
3. **A course from another host.** Upstream's `determineCourseUrl` turns `reference-course` into
   `https://reference-course.netlify.app/tutors.json`. What would rung 4 need to do the same? Which rule
   would you have to change, and who decides?
4. **Contrast the warnings.** Upstream silences `state_referenced_locally`; rung 4 fails on it. Write two
   sentences for each choice.
5. **Your own course.** Run `node apps/cli/src/main.ts --json-only <your course> apps/reader/static/courses/mine`
   on the course you wrote in topic 1, then open `/course/mine`. What does the reader show for kinds rung 4
   does not build?
