# Break a rule

Each of these takes one line. Make the change, run `pnpm test`, read the failure, then undo the change.

## Raw HTML

In `apps/reader/src/lib/ui-components/layout/Card.svelte`, change `<p>{cardDetails.summary}</p>` to
`<p>{@html cardDetails.summary}</p>`.

~~~
Raw HTML rule: {@html} bypasses Svelte's escaping, so the reader uses it in one place,
lib/ui-primitives/Markdown.svelte, on what renderMarkdown from @ladder/lite returns (it escapes first).
Show course text with {text}, which Svelte escapes, or as <Markdown markdown={...} />. Sanitising author
HTML arrives in rung 6 (Guarded).
  apps/reader/src/lib/ui-components/layout/Card.svelte
~~~

## A primitive that reaches for data

In `apps/reader/src/lib/ui-primitives/Icon.svelte`, add
`import { currentLo } from "../runes/index.svelte.ts";`.

~~~
Reader layering rule: lib/ui-primitives may import only [nothing else in the reader], because primitives
(Icon, Markdown) are the smallest pieces; like upstream's ui-primitives they import no data, so any layer
above can use them. ...
~~~

Compare upstream's rule `ui-primitives-no-data-features` in `.dependency-cruiser.cjs`.
