# Follow a URL

Open <http://localhost:5173/topic/ladder-sample-course/topic-02-practice> with the browser's Network tab
open. Reload. One request fetches `tutors.json`. Everything below happens around it.

| Step | File (under `apps/reader/src`) | What happens |
| --- | --- | --- |
| 1 | `routes/+layout.ts` | `ssr = false`: this page renders in the browser |
| 2 | `routes/(course-reader)/+layout.svelte` | wraps the page in `TutorsShell`; focuses `#main-content` after navigating |
| 3 | `routes/(course-reader)/topic/[courseid]/[...loid]/+page.ts` | `params.courseid` is `ladder-sample-course` |
| 4 | `lib/course/course-service.ts` | `readCourse`: cache miss, `fetch("/courses/ladder-sample-course/tutors.json")` |
| 5 | `lib/course/lo-tree.ts` | `decorateCourseTree`: ids into routes, `loIndex`, parents |
| 6 | `lib/course/lo-tree.ts` | `findLo(tree, url.pathname)` finds the topic |
| 7 | `lib/runes/index.svelte.ts` | the load sets `currentCourse.value` and `currentLo.value` |
| 8 | `routes/(course-reader)/topic/[courseid]/[...loid]/+page.svelte` | `<Composite composite={data.topic} />` |
| 9 | `lib/ui-components/structure/Composite.svelte` | breadcrumbs, `h1`, then `arrange(composite)` into units, sides and cards |
| 10 | `lib/ui-navigators/SecondaryNavigator.svelte` | `breadCrumbs(currentCourse.value, lo)` |
| 11 | `lib/ui-components/layout/Units.svelte`, `Cards.svelte` | a box per unit, a grid of cards |
| 12 | `lib/ui-components/layout/Card.svelte` | the link, title, `Icon` and summary you see |

Open each file as you go. None is longer than a screen.

## Now click

Click the **Ladder Sample Course** breadcrumb, then the **Basics** topic. Watch the Network tab: no second request for
`tutors.json`. Which line in `course-service.ts` prevented it?
