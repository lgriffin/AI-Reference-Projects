# Acceptance criteria

Written as EARS sentences, one "shall" each. Rung 5 (Proven) teaches EARS in full.

| Id | Criterion |
| --- | --- |
| AC1 | The reader shall show a navigation landmark labelled "Learning object pager" on every talk, note and lab page. |
| AC2 | While the learning object on screen is not the first in reading order, the pager shall link to the previous one, showing its title. |
| AC3 | While the learning object on screen is not the last in reading order, the pager shall link to the next one, showing its title. |
| AC4 | The reader shall take reading order to be the course's talks, notes and labs in the order `tutors.json` holds them. |
| AC5 | The pager's logic shall live in `apps/reader/src/lib/course/lo-pager.ts`, with unit tests in `apps/reader/tests/lo-pager.test.ts`, and its component in `apps/reader/src/lib/ui-navigators/LoPager.svelte`. |
| AC6 | When `pnpm test` is run, the variant shall pass, with the reader layering rules unchanged. |
| AC7 | When `pnpm test:e2e` is run, the smoke test shall still pass. |

AC1 to AC5 are checked by the grading tests in the next step. AC6 and AC7 are the variant's own gates. A
person reads your unit tests: they should cover the first, a middle and the last stop, and a learning object
that is not a stop.
