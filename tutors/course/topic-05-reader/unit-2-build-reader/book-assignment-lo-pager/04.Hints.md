# Hints

Take one at a time. Each says a little more than the last.

1. **Where is the order already?** `decorateCourseTree` in `lib/course/lo-tree.ts` walks the course once,
   in pre-order, and fills `loIndex` as it goes. A `Map` keeps insertion order.
2. **Which kinds are stops?** `loIndex` holds pages: course, topics, talks, notes and labs. Filter it to
   `talk`, `note` and `lab`, and you have `readingOrder`.
3. **Neighbours.** Find the learning object's index in that list by its `route` (objects in the tree are the
   decorated copies, so compare routes, not the raw JSON). Previous is `index - 1`, next `index + 1`. Not
   found means no neighbours.
4. **Write the tests first.** `apps/reader/tests/lo-tree.test.ts` shows how to load upstream's file and
   decorate it. Assert the three titles, then the ends.
5. **The component.** `LoPager.svelte` takes `lo` with `$props()`, reads `currentCourse.value` from
   `lib/runes`, and computes `{ previous, next }` with `$derived`. Look at `SecondaryNavigator.svelte`: it has
   the same shape.
6. **Placing it.** Import it in `Note.svelte` and `Lab.svelte` and render `<LoPager lo={...} />` after the
   content. The reader layering rule lets `ui-components` import `ui-navigators`; it does not let
   `ui-primitives` do so, so do not put it there.
7. **The lab has two pagers.** Give yours `aria-label="Learning object pager"`; the lab's own is
   "Step pager". Run `pnpm test:e2e` to see the smoke test still finds its links.
