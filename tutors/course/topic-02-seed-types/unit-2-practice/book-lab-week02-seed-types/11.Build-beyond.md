# Build beyond (Create)

Start the assignment first; these go further. Pick at least one, and start it from the value it adds: say
which customer (student, lecturer, contributor) it serves.

1. **Make the table a type.** Rewrite `folderKinds` so the compiler demands an entry for every `LoType`, as
   `preOrder` does, while still recognising the kinds rung 1 skips. What does it cost? Is it worth it?
2. **A kinds report.** Turn `kinds.mjs` into a test: build the reference course with rung 1 and assert the
   count of each kind rung 1 builds. Where should the expected counts come from so the test is an oracle, not
   a snapshot?
3. **`panelvideo`.** Upstream sets a `panelvideo`'s `route` from the `videoid` file (`readVideoIds` and
   `getVideo` in `packages/jsr/gen/src/utils/lr-utils.ts`). Add the kind and compare with the three
   `panelvideo` objects upstream writes for the reference course.
4. **A friendlier skip.** Rung 1 prints "skipped ... this rung does not build this kind". Make it name the
   rung or week that would build it, without breaking the fence.

Run `npm test` after every change. Do not edit `tests/rung-fence.test.ts` or the oracle.
