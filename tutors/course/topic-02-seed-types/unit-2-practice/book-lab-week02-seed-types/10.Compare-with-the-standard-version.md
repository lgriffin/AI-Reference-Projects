# Compare with the standard version (Analyse, Evaluate)

This is the last week of rung 1. Before you build beyond it, set your work beside rung 1's standard version:
the zip in this week's practice unit, "Rung 1 (seed): the standard version" (`rung-1-seed.zip`). It is the
agreed baseline for the whole class, proven before it was written: it passes its gate and runs on the sample
course.

Unzip a fresh copy somewhere new, so it does not touch yours, and run its gate:

~~~bash
rm -rf /tmp/standard-1 && mkdir /tmp/standard-1 && cd /tmp/standard-1
unzip -q ~/Downloads/rung-1-seed.zip
cd tutors-ladder/rung-1-seed && npm test
~~~

~~~
# tests 11
# suites 0
# pass 11
# fail 0
~~~

Now compare it with your copy, which holds this week's experiments and, if you have started, the
assignment:

~~~bash
diff -r --exclude=node_modules --exclude=out /tmp/standard-1/tutors-ladder/rung-1-seed $SEED
cd $SEED && git diff --stat $(git rev-list --max-parents=0 HEAD)
~~~

The first command lists every file you have changed. The second does the same through Git, against your
first commit. If you restored every break in steps 6 and 7, the only differences are the ones you meant.

## Judge the difference

For each difference, decide:

- **Kept**: it is part of the assignment or a Build beyond extension, and the gate is green with it.
- **Leftover**: a break you forgot to restore, an `out/` folder, a stray file. Remove it.
- **Better than the baseline?** If you think a change improves the standard version itself (a clearer message,
  a missing test), write it down. That is a Kaizen proposal for step 12.

Delete `/tmp/standard-1` when you are done.
