# Objectives

Run the rung 1 generator, read what it writes, and hold it up against the real one. Build the shared fixture
and the Tutors reference course with both generators, compare them, break the exhaustive `switch` and the
prefix table on purpose to see which level catches each, and experiment on upstream.

## Learning outcomes

| Outcome | Level | Steps |
| --- | --- | --- |
| Explain how the discriminated union and `assertNever` make a missing case a compile error | Understand | 2, 6 |
| Build a course with rung 1 and with upstream, and compare the outputs with a small tool | Apply | 3, 4, 5 |
| Break the `switch` and the prefix table, and say which level (L5 or L3) catches each | Analyse | 6, 7 |
| Judge an oracle test against hand-written expectations and snapshots | Evaluate | 4, 7 |
| Compare your work with rung 1's standard version and judge each difference | Evaluate | 10 |
| Write the week's rule as an informal EARS sentence, and improve one piece of standard work | Evaluate, Create | 8, 12 |

Each step's heading names its Bloom level. The last two steps are Build beyond (Create) and Kaizen (Evaluate).

You need Node.js 22.18 or later, Deno 2, the three clones from Lab 1, and the `LADDER` and `MONO` variables.
Allow about ninety minutes. Then start the assignment, "The github kind".
