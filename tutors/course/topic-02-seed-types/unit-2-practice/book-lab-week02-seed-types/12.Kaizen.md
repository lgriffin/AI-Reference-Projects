# Kaizen (Evaluate)

Ten minutes, in your notes.

1. **Name one waste** you met this week. Candidates: *defects* caught late (a broken table that only the
   conformance test noticed); *relearning* (installing TypeScript again with `--no-save`); *waiting* (Deno's
   first download); *task switching* between the variant and the upstream clone.
2. **Find its root cause.** Ask "why?" two or three times.
3. **Improve the standard work.** This week's standard work is the Single Gate and `AGENTS.md`. Propose one
   change to either that would have removed your waste. Examples: a `typecheck` script you run by habit
   before `npm test`; a line in `AGENTS.md` that says "a change to `folderKinds` needs a test", or better, a
   test that makes that line unnecessary.

Write it as "I will ... so that ...". `AGENTS.md` and the tests are behind the Human Boundary: write your
change as a proposal a person can accept, not as an edit an agent makes alone.
