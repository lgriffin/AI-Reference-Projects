## 1. A folder of no kind, upstream

~~~bash
cd /tmp/ladder-fixture
mv topic-01-basics/unit-1-intro/note-1-reading topic-01-basics/unit-1-intro/reading
deno run -A $MONO/packages/jsr/tutors-cli/main.ts validate
~~~

~~~
error V002 topic-01-basics/unit-1-intro/reading: The folder "reading" won't appear in your course, nor will anything inside it, because its name doesn't start with a kind Tutors knows (topic, unit, talk, note, lab and so on). Rename it to topic-reading.
1 error, 0 warnings. Fix the errors before publishing.
It can be fixed for you: run tutors validate --fix.
~~~

The suggested name, `topic-reading`, is a guess, and here a wrong one: the folder holds a note. A teaching
failure is only as good as its remedy. Which name would you have suggested?

Rung 1 does the same as the generator: `folderKind("reading")` is `undefined`, and `children` skips it. Find
the line. Then find `namesItsKind` and `pruneTree` in upstream
`packages/jsr/gen/src/services/resource-builder.ts`, which do the same job. Rename the folder back.

`default:` with nothing after it. Open `packages/jsr/model/src/types/learning-objects.ts`: `Lo.type` is a
`string`. Write down what would happen upstream if someone added `"slides"` to `simpleTypes` in
`packages/jsr/model/src/types/type-utils.ts` and forgot a `case`. Then open
`packages/jsr/types/src/learning-objects.ts` and its `README.md`: how far has upstream got towards L5?
