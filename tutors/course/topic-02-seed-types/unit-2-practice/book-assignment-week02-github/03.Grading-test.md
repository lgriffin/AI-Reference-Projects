# The grading test

The grading test is already in the variant: `variants/rung-1-seed/tests/assignment/github-kind.test.ts`.
It is skipped unless you ask for it, so the gate stays green before you start. It sits in
`tests/assignment/`, which the gate's `tests/*.test.ts` does not reach.

## Run it

~~~bash
cd $LADDER/variants/rung-1-seed
LADDER_ASSIGNMENT=1 node --test tests/assignment/*.test.ts
~~~

Before you start, all four tests fail:

~~~
not ok 1 - AC1: a folder whose name starts with github is a github learning object
not ok 2 - AC2: github sorts after web and before archive, as upstream preOrder says
not ok 3 - AC3 and AC4: a github link takes its route from the first line of githubid, wherever it sits
not ok 4 - AC5: a github folder without githubid still builds, with an empty route
# pass 0
# fail 4
~~~

When you are done, `# pass 4`. Without the variable, the same command reports `# skipped 4`.

## How it is built

The test writes a small course into a temporary folder: a topic holding a note, a web link, a `github`
link and an archive, and a unit holding a second `github` link whose `githubid` ends in `\r\n` and has a
second line. It builds the course with `buildCourse`, keeps the fields `type`, `id`, `title`, `summary` and
`route`, and compares the topic with `UPSTREAM`:

~~~ts
/** What upstream wrote for topic-01-code, cut to the fields this rung builds. */
const UPSTREAM: Json = {
  type: "topic", id: "topic-01-code", title: "Code", summary: "Where the code is.", route: "/topic/{{COURSEURL}}/topic-01-code",
  los: [
    { type: "unit", id: "unit-1-more", ..., los: [{ type: "github", id: "github-2-second", ..., route: "https://github.com/tutors-sdk/tutors-reference-course" }] },
    { type: "note", id: "note-1-intro", ... },
    { type: "web", id: "web-1-docs", ..., route: "https://tutors.dev" },
    { type: "github", id: "github-1-repo", ..., route: "https://github.com/tutors-sdk/tutors-mono-repo" },
    { type: "archive", id: "archive-1-solutions", ... },
  ],
};
~~~

`UPSTREAM` was captured by running upstream `tutors build` (tutors-mono-repo `2b96b69`) on exactly that
course. It is an oracle, like the fixture's: do not edit it to make the test pass.

## Check it yourself against upstream

Build the reference course with your rung 1 and with upstream (Lab 2, step 5), and run `kinds.mjs` again. The
`github` line should read `github  2  2`. Then open both files and compare the two `github-1-template-1`
objects by eye: same `title` (with its double space), `summary` and `route`.
