## What climbing means

Rung 2 is a copy of rung 1 with a renderer added. Its fence changes one rule: HTML output becomes allowed and
client-side script is refused instead. You will see that change with `diff` in Lab 3. Before you start, read
`variants/rung-2-lite/RUNG.md`. If you work with an agent, start its first rung 2 session by asking it to read
rung 2's `AGENTS.md`, not rung 1's.
