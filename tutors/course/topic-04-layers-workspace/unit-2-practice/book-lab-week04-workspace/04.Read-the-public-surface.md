## What moved, and what did not

Rung 3 started from a copy of rung 2. Compare a file that moved into a package:

~~~bash
diff ../rung-2-lite/src/markdown.ts packages/lite/src/markdown.ts && echo same
diff ../rung-2-lite/src/site-builder.ts packages/lite/src/site-builder.ts | head -30
~~~

`markdown.ts` prints `same`: it moved without a change. `site-builder.ts` changed its imports, and it gained its
**own** `assertNever` at the bottom. Answer:

1. Where did rung 2's `site-builder.ts` get `assertNever` from?
2. If `lite` imported it from `@ladder/gen` instead, which rule would fail?
3. Is copying four lines of code a smell here, or a good trade? Say why in one sentence.
