# Walk the workspace (Understand)

## The packages and their links

~~~bash
pnpm -r ls --depth 0
~~~

~~~
@ladder/rung-3-layers@1.0.0 . (PRIVATE)

devDependencies:
@types/node 22.20.7
typescript 6.0.3

@ladder/cli@1.0.0 ./apps/cli (PRIVATE)

dependencies:
@ladder/gen link:../../packages/gen
@ladder/lite link:../../packages/lite

@ladder/gen@1.0.0 ./packages/gen (PRIVATE)

dependencies:
@ladder/model link:../model

@ladder/lite@1.0.0 ./packages/lite (PRIVATE)

dependencies:
@ladder/model link:../model
~~~

`@ladder/model` has no dependencies, so it has no entry. `link:` means a symbolic link, not a copy:

~~~bash
ls -l packages/gen/node_modules/@ladder apps/cli/node_modules/@ladder
~~~

~~~
apps/cli/node_modules/@ladder:
gen -> ../../../../packages/gen
lite -> ../../../../packages/lite

packages/gen/node_modules/@ladder:
model -> ../../../model
~~~

So `import type { Course } from "@ladder/model"` in `gen` resolves to `packages/model/package.json`, whose
`exports` points at `src/index.ts`. Edit `model` and `gen` sees it at once; there is no build step.
