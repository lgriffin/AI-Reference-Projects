# Start from the standard version, install and run (Apply)

## Start from rung 2's standard version

The class builds on one agreed baseline. Download the zip in week 3's practice unit, "Rung 2 (lite): the
standard version", and unzip it in a working folder:

~~~bash
mkdir -p ~/ladder && cd ~/ladder
unzip ~/Downloads/rung-2-lite.zip
ls tutors-ladder
~~~

~~~
fixtures  rung-2-lite
~~~

Rung 3 is a copy of rung 2 that changes structure. Put rung 3 beside it, from your clone of
AI-Reference-Projects, and give it a Git history so that every break in this lab can be undone:

~~~bash
cp -r $LADDER/variants/rung-3-layers tutors-ladder/
cd tutors-ladder/rung-3-layers
git init -q && git add -A && git commit -qm "rung 3, as shipped"
~~~

Every command in this lab runs from `tutors-ladder/rung-3-layers`, with `../fixtures` and `../rung-2-lite`
beside it.

## Install

Rung 3 is the first rung with an install. It pins pnpm in its `package.json`
(`"packageManager": "pnpm@10.28.0"`). Install that version if you do not have pnpm 10:

~~~bash
npm install --global pnpm@10.28.0
pnpm install
~~~

The install brings two dev dependencies, `typescript` and `@types/node`, and links the four workspace
packages to each other. (`node_modules` is in `.gitignore`, so Git ignores it.)

## The Single Gate

~~~bash
pnpm test
~~~

It runs `pnpm typecheck` first (one `tsc -p` per package, then the tests' project), then every suite. The end
of the output:

~~~
# tests 76
# suites 15
# pass 69
# fail 0
# cancelled 0
# skipped 7
~~~

The seven skipped tests are next week's assignment, waiting for you. Now run the tools:

~~~bash
pnpm start ../fixtures/ladder-sample-course out
~~~

~~~
wrote 8 pages and tutors.json to /home/you/ladder/tutors-ladder/rung-3-layers/out
~~~

The same 8 pages as rung 2. Check it: run rung 2 on the same course and compare the pages.

~~~bash
(cd ../rung-2-lite && node src/main.ts ../fixtures/ladder-sample-course /tmp/out2)
diff -r out /tmp/out2 && echo "same site"
~~~

Then delete `out/` and `/tmp/out2`. Write down how long `pnpm test` took: you will use the number in the
Kaizen step.
