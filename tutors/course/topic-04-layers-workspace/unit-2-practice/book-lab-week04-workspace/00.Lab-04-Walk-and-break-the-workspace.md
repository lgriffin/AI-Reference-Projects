# Objectives

Install the rung 3 workspace and run its Single Gate. Walk its packages and links, read each package's
public surface, then break every direction rule on purpose and read what each failure tells you. Name the
week's rule, compare rung 3 with upstream's layers, build beyond the variant, and end with a Kaizen step.

## Learning outcomes

| Outcome | Level | Steps |
| --- | --- | --- |
| Explain what `pnpm-workspace.yaml`, `exports` and `workspace:*` each do | Understand | 3, 4 |
| Install and run the workspace, and trace how `@ladder/gen` resolves `@ladder/model` | Apply | 2, 3 |
| Diagnose a Layering, Package boundary, Model or Closure failure and choose the fix that respects the reason | Analyse | 5, 6, 7 |
| Compare rung 3's layers with upstream's `ARCHITECTURE.md` and `.dependency-cruiser.cjs` | Analyse | 9 |
| Write the dependency-direction rule as an informal EARS sentence and judge its Assertion Ladder level | Evaluate | 8 |
| Design an extension of the workspace that keeps the arrows inward | Create | 10 |

Each step's heading names its Bloom level.

You need Node.js 22.18 or later, Git, and the `LADDER` and `MONO` variables from Lab 1 (`LADDER` is
`AI-Reference-Projects/tutors`, `MONO` your clone of tutors-mono-repo). Allow about two hours. Every break
is undone with `git checkout` before the next.
