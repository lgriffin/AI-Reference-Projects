# Week 1: The course format as data

Rung 1 of 7: Seed

Meet Tutors, a generator and a reader joined by one file, `tutors.json`. Meet the two ladders this module
climbs: the capability ladder (what you build) and the Assertion Ladder (how each rung stays safe when you work
with a coding agent). Then write a tiny course, prove it is compliant with the real Tutors rules, and turn it
into data with the smallest Tutors generator: rung 1, Seed.

## Learning outcomes

By the end of this week you will be able to:

1. **(Remember)** List the folder prefixes Tutors reads as learning-object kinds, and the file each kind needs.
2. **(Understand)** Explain how a course folder becomes `tutors.json`, and how the reader and the validator each
   use the course format.
3. **(Apply)** Write a small course, validate it with `tutors/scripts/check-course.sh`, and build it with the
   rung 1 generator.
4. **(Understand)** Describe the capability ladder and the Assertion Ladder, and say which level (L0 to L5)
   guards a given rule.
5. **(Create)** Write the week's rule as an informal EARS "shall" sentence.
