# Write a tiny course (Remember, Apply)

Make a new folder outside the repositories, for example `~/src/my-course`, and create these files.

~~~
my-course/
  course.md
  properties.yaml
  topic-01-hello/
    topic.md
    note-1-welcome/
      note.md
    web-1-tutors/
      web.md
      weburl
~~~

You can type them in an editor, or run this:

~~~bash
mkdir -p ~/src/my-course/topic-01-hello/{note-1-welcome,web-1-tutors} && cd ~/src/my-course
printf '# My First Course\n\nA tiny course I wrote while setting up Tutors.\n' > course.md
printf 'credits: Written by me, on the Tutors Ladder course\n' > properties.yaml
printf '# Hello\n\nA first topic, with one note and one link.\n' > topic-01-hello/topic.md
printf '# Welcome\n\nThis is my first Tutors note. It is **Markdown**.\n' > topic-01-hello/note-1-welcome/note.md
printf 'Tutors\n\nThe home of Tutors.\n' > topic-01-hello/web-1-tutors/web.md
printf 'https://tutors.dev\n' > topic-01-hello/web-1-tutors/weburl
~~~

## What each file is for

| File | Role in the format |
| --- | --- |
| `course.md` | the course: first line is the title, next non-blank line the summary |
| `properties.yaml` | course settings; upstream's generator reads it (rung 1 does not) |
| `topic-01-hello/topic.md` | the topic's descriptor: its title and summary |
| `note-1-welcome/note.md` | the note: title, summary and the body readers see |
| `web-1-tutors/web.md` | the link card's title and summary |
| `web-1-tutors/weburl` | the link itself, and nothing else |

The kinds come from the folder names: `topic-`, `note-`, `web-`. Look back at the table in the talk "The
course as data" and name the extra file a `talk-`, a `book-` and an `archive-` folder each need.
