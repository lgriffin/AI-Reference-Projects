## Build the same course with upstream

The upstream generator works in the current folder and writes `json/` there, so build a copy:

~~~bash
rm -rf /tmp/my-course-up && cp -r ~/src/my-course /tmp/my-course-up && cd /tmp/my-course-up
deno run -A $MONO/packages/jsr/tutors-cli/main.ts build
~~~

~~~
: my-course-up : My First Course
--: topic-01-hello : Hello
----: note-1-welcome : Welcome
----: web-1-tutors : Tutors
tutors: 5.3.0
~~~

Deno may also print warnings about a `vitest-cucumber` bin; they are harmless (CONTRIBUTING.md says so).
The log comes from `buildLo` in `packages/jsr/gen/src/services/course-builder.ts`: one line per folder.

authLevel contentMd frontMatter hide id img imgFile route summary title type video videoids

parser, and why does that keep them off rung 1?
