# Build beyond (Create)

You are expected to take rung 1 further than it goes. Pick at least two. Stay inside the Rung Fence: run
`npm test` after every change, and if the fence fails, the idea belongs to a later rung.

1. **A talk and a lab in your course.** Add `topic-01-hello/talk-1-intro/` with a `talk.md` and a Marp deck
   `intro.marp` that starts with `marp: true`, and `topic-01-hello/book-1-first-lab/` with
   `00.Lab-01-First.md`, `01.Second.md` and `img/main.png`. Validate, build with rung 1 and with upstream, and
   explain the lab's `title` from `buildLab`. Then delete `marp: true` and read what V015 says.
2. **An outline command.** Write `~/ladder-tools/outline.mjs`: given two `tutors.json` files, print each tree
   as `type id: title` lines, indented by depth, side by side, with `=` or `!` between them. Use it to compare
   rung 1's and upstream's output for your course. (Week 2 uses a tool like this.)
3. **A `--summary` option.** Give rung 1's CLI an option that prints how many objects of each kind it built,
   instead of writing a file. Where does the option belong (`AGENTS.md`, "Where things go")? Add a test that
   calls `buildCourse` and counts, rather than one that runs the CLI.
4. **A friendlier error.** When the course folder does not exist at all, rung 1 says it has no `course.md`.
   Make it say the folder does not exist, with its own exit code, and decide whether that code should be 1.

Bring one extension to next week's class and be ready to explain every line of it.
