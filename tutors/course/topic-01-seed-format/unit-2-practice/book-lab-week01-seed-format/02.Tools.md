# Tools (Apply)

You need four tools. The versions come from the upstream mono-repo itself.

| Tool | Version | Why | Where the version is pinned |
| --- | --- | --- | --- |
| Git | any recent | to clone the repositories | - |
| Node.js | 26.13.0 or later | the mono-repo's apps and tests | `engines` in `package.json`, and `.nvmrc` |
| pnpm | 11.24.0 | the mono-repo's package manager | `packageManager` in `package.json` |
| Deno | 2.9.6 | the generator, the validator and everything in `packages/jsr/` | `.dvmrc` |

The ladder's own variants need only Node.js 22.18 or later, because they run TypeScript with Node's built-in
type stripping. Node.js 26.13.0 satisfies both, so install that once.

## Node.js

Use a version manager such as [nvm](https://github.com/nvm-sh/nvm) (macOS, Linux, WSL) or
[nvm-windows](https://github.com/coreybutler/nvm-windows). Once you have cloned the mono-repo (next step),
`nvm install` in its folder reads `.nvmrc` and installs the pinned version.

~~~bash
node --version   # v26.13.0 or later (the variants accept v22.18 or later)
~~~

## pnpm

Do not install pnpm globally yet. The mono-repo's quick start installs the exact version its `package.json`
pins (next step). You only need pnpm for the upstream reader and, from week 4, for rung 3 and above.

## Deno

Follow the instructions at [deno.com](https://deno.com/), then check the version:

~~~bash
deno --version
~~~

~~~
deno 2.9.6 (stable, release, x86_64-unknown-linux-gnu)
~~~

Your platform string may differ. Any Deno 2 runs this week's commands.
