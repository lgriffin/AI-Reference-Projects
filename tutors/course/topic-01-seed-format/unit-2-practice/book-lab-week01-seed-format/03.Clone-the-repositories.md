# Clone the repositories (Apply)

Make a folder for the module and clone three repositories into it. This lab uses `~/src`; use whatever you
like, and change the paths below to match.

~~~bash
mkdir -p ~/src && cd ~/src
git clone https://github.com/tutors-sdk/tutors-mono-repo.git
git clone https://github.com/tutors-sdk/tutors-reference-course.git
git clone https://github.com/lgriffin/AI-Reference-Projects.git
~~~

| Repository | What you use it for |
| --- | --- |
| `tutors-mono-repo` | the real generator, validator and reader: the Summit, and the oracle for every rung |
| `tutors-reference-course` | a course that uses every learning-object kind |
| `AI-Reference-Projects` | this module: `tutors/variants/` (one folder per rung) and `tutors/scripts/check-course.sh` |

The module pins the mono-repo at commit `2b96b69`. To see exactly what the module saw:

~~~bash
cd ~/src/tutors-mono-repo && git checkout 2b96b69b6e99ffde04cf29a17b7e377e9d9c9510
~~~

Set two variables for the rest of the module. Put them in your shell profile so every lab can use them:

~~~bash
export LADDER=~/src/AI-Reference-Projects/tutors
export MONO=~/src/tutors-mono-repo
~~~

## Optional: run the real reader

If you have Node 26.13 or later, follow the mono-repo's quick start (its `README.md`, "Quick start"):

~~~bash
cd $MONO
npm install --global "$(node -p "require('./package.json').packageManager")"
pnpm install
cp .env.example .env
pnpm dev
~~~

and open **http://localhost:5173/course/reference-course**. The `.env` sets `PUBLIC_ANON_MODE=TRUE`, so no
Supabase project or OAuth app is needed. `pnpm install` is large (CONTRIBUTING.md warns of over 800 MB). If you
skip this now, you will run the reader in week 8.
