# Objectives

Set up the tools the whole module uses, write a tiny Tutors course, prove it is compliant with the real
Tutors rules, and turn it into data with the rung 1 generator. Then read the data, compare it with what
upstream writes, and name the week's rule.

## Learning outcomes

| Outcome | Level | Steps |
| --- | --- | --- |
| List the folder prefixes Tutors reads as kinds, and the file each kind needs | Remember | 4 |
| Explain how a course folder becomes `tutors.json`, and how the validator reads the same folder | Understand | 5, 6, 7 |
| Write a small course, validate it with `check-course.sh` and build it with rung 1 | Apply | 4, 5, 6 |
| Say which Assertion Ladder level guards a given rule | Understand | 5, 9 |
| Write the week's rule as an informal EARS "shall" sentence | Create | 8 |
| Name one waste in the value stream or your own work, and one improvement | Evaluate | 11 |

Each step's heading names its Bloom level. The last two steps are Build beyond (Create) and Kaizen
(Evaluate). Allow about two hours, most of it downloading.

You need a terminal, Git and about 2 GB of disk. Everything else is installed in step 2.
