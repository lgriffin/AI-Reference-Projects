# Run the seed generator (Apply)

Now build the same course with rung 1. It needs no install.

~~~bash
cd $LADDER/variants/rung-1-seed
npm test
~~~

The end of the output:

~~~
# tests 11
# suites 0
# pass 11
# fail 0
~~~

That is the Single Gate: every test, including the Rung Fence. Now run the generator on your course:

~~~bash
node src/main.ts ~/src/my-course out/tutors.json
~~~

~~~
wrote /home/you/src/AI-Reference-Projects/tutors/variants/rung-1-seed/out/tutors.json: 1 topics
~~~

`out/` is in `.gitignore`. Open `out/tutors.json`:

~~~json
{
  "title": "My First Course",
  "summary": "A tiny course I wrote while setting up Tutors.",
  "contentMd": "# My First Course\n\nA tiny course I wrote while setting up Tutors.\n",
  "id": "my-course",
  "route": "/",
  "type": "course",
  "los": [
    {
      "title": "Hello",
      "summary": "A first topic, with one note and one link.",
      "contentMd": "# Hello\n\nA first topic, with one note and one link.\n",
      "id": "topic-01-hello",
      "route": "/topic/{{COURSEURL}}/topic-01-hello",
      "type": "topic",
      "los": [
        {
          "title": "Welcome",
          "summary": "This is my first Tutors note. It is **Markdown**.",
          "contentMd": "# Welcome\n\nThis is my first Tutors note. It is **Markdown**.\n",
          "id": "note-1-welcome",
          "route": "/note/{{COURSEURL}}/topic-01-hello/note-1-welcome",
          "type": "note"
        },
        {
          "title": "Tutors",
          "summary": "The home of Tutors.",
          "contentMd": "Tutors\n\nThe home of Tutors.\n",
          "id": "web-1-tutors",
          "route": "https://tutors.dev",
          "type": "web"
        }
      ]
    }
  ]
}
~~~

## Read it

Compare it with what you predicted in step 4.

- The course's `id` is the folder's name, `my-course`.
- The topic's `route` holds `{{COURSEURL}}`, a placeholder the reader fills in.
- The web link's `route` is the first line of `weburl`. Its `title` has no `#` to drop.
- The note's body is still Markdown: `**Markdown**`. HTML is rung 2's job.

## Exit codes

~~~bash
node src/main.ts; echo "exit $?"
node src/main.ts ~/src/nothing-here; echo "exit $?"
~~~

~~~
usage: node src/main.ts <courseFolder> [outFile]
exit 2
/home/you/src/nothing-here has no course.md, so it is not a Tutors course.
exit 1
~~~

Without an output file, the generator writes `json/tutors.json` inside the course folder, as upstream does.
