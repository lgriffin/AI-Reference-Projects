# Acceptance criteria

Written as EARS sentences, one "shall" each. Each maps to a module outcome in `course.md`; all are assessed
at **Create**, because together they are two rules you specify, build and prove.

| Id | Criterion | Module outcome |
| --- | --- | --- |
| AC1 | `REQUIREMENTS.md` shall hold, after R-036, a requirement that says what the generator shall do with raw HTML and a requirement that says what the policy shall do with a locked route, and the EARS audit shall report no finding. | M6 |
| AC2 | The generator package shall export `rawHtmlFindings(markdown)`. | M7 |
| AC3 | When Markdown prose holds a raw tag that names an HTML element, `rawHtmlFindings` shall return that element's lower-case name, once, in order of first appearance. | M7 |
| AC4 | While text is inside a fenced block or an inline code span, or only resembles a tag (a comparison, a generic type, an arrow, an autolink), `rawHtmlFindings` shall not report it. | M7 |
| AC5 | When `buildCourse` reads a Markdown or Marp file holding raw HTML, the generator shall warn once per file and element, with a message that starts `raw-html <path>:` and names the element in angle brackets. | M7 |
| AC6 | When a learning object's route, or one of its ancestors' routes, is locked, `isLoRouteLocked` shall return true; a lock on a course id alone shall lock nothing, an unlocked entry shall lock nothing, and trailing slashes shall be ignored. | M7 |
| AC7 | `isLoRouteLocked` shall take time linear in the length of the route, however many slashes it ends with. | M7 |
| AC8 | If the role is not `educator`, then `canSeeLo` shall return false for a locked route; for an educator it shall return true. | M7 |
| AC9 | When `pnpm test` is run, the variant shall pass, with the Purity rule, the Rung Fence, `security/audit-allowlist.json` and both Content Security Policies unchanged. | M7, M2 |
| AC10 | The history shall show both requirements committed before the code that implements them. | M6 |

AC1 to AC8 are checked by the grading test in the next step. AC9 is the variant's own gate. AC10 is read by
a person.

## The cases the grading test uses

Part A's corpus holds eleven raw-HTML inputs (`<iframe>`, `<script>`, `<object>`, `<embed>`, `<form>` with
an `<input>`, `<svg/onload>`, `<img onerror>`, `<style>`, a raw `<a href="javascript:...">`,
`<meta http-equiv="refresh">`, an upper-case `<IFRAME>`) and seven look-alikes that must not be reported.
Part B's table of nine cases is upstream's: `guides/RBAC.md` ("Descendant Route Filtering") and
`tests/unit/rbac/lock-matching.test.ts`.
