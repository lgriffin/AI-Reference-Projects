# Break a defence, and ask why five times (Evaluate)

Seeding a violation shows which level of the Assertion Ladder catches it, and what the failure teaches.

## Take out the sanitiser

Ask yourself, or your agent, to "simplify markdown.ts". Suppose it takes out the sanitiser. Make that change
by hand in `packages/lite/src/markdown.ts`:

~~~ts
// before
const safe = safeUrl(url!, bang ? "image" : "link");
// after
const safe: string | null = url!;
~~~

~~~bash
pnpm vitest run 2>&1 | grep -E "AssertionError: XSS|Test Files|Tests "
~~~

Fourteen red tests in four files. Read the full output and sort them by tier:

| Tier | File | What it tells you |

course URL must pass safeUrl (packages/lite/src/url.ts) before it reaches an href or src." Which line of a
failure would you want an agent to read first? Undo with `git checkout .` and run `pnpm test` until green.

## Five Whys on the escape

In step 4 a `\u0001javascript:` address escaped your own defence with the gate green. Do a Five Whys on it
in your learning log. Start from the symptom and do not stop at a line of code:

1. Why would script run? ...
2. Why did `allowedLink` allow it? ...
3. Why did no test notice? ...
4. Why was there only one payload? ...
5. Why ...?

A good fifth answer names something about the **way of working**, not the code: a sentence that named one
attack, a proof with one example, an oracle that was the author's own idea of a URL. Then write the
countermeasure for each why, and find it in rung 6: the wider sentence, the corpus, the property, the
independent oracle (`tests/support/xss-oracle.ts`), the CSP.

## Try two more

1. In `apps/cli/src/node-file-system.ts`, change `containedPath(path)` to `path`. Two tests fail. Which
   rule names the fix, and which contract case names the path that got through?

   ~~~
   AssertionError: Containment rule: an adapter is where a path meets the real files, so it is where a path is checked. ...
   AssertionError: readText(/etc/passwd)
   ~~~

2. In `packages/rbac/src/index.ts`, add `let lastCheck = 0;` above `canView` and set
   `lastCheck = Date.now();` inside it. Run `pnpm vitest run tests/architecture` and read the Purity rule's
   message. Why does a pure policy make the table test the whole truth?

Undo both.

## Evaluate

For each of the three breaks, write the Assertion Ladder level that caught it (L3 Checked, L4 Explained,
L5 Prevented) and one sentence on whether a higher level is possible and worth its cost.
