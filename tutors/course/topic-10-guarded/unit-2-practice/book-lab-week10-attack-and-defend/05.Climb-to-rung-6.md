## Read outside the course

The generator runs as you. Make a copy of the hostile course whose `course.md` is a symbolic link to a
"private" file that lives outside the course:

~~~bash
cp -r tests/fixtures/hostile-course $LAB/linked
mkdir -p $LAB/home && printf '# My private notes\n\nThe exam answers are 42.\n' > $LAB/home/notes.md
rm $LAB/linked/course.md
ln -s $LAB/home/notes.md $LAB/linked/course.md
~~~

Build it with rung 5, then with rung 6:

~~~bash
(cd ../rung-5-reader && pnpm -s start $LAB/linked $LAB/rung-5-linked)
grep -o '<h1>[^<]*</h1>\|The exam[^<]*' $LAB/rung-5-linked/index.html
pnpm -s start $LAB/linked $LAB/rung-6-linked; echo "exit $?"
~~~

With rung 5 your private file became the course's home page. Rung 5's `NodeFileSystem` skips links when it
lists a folder, but `course.md` is never listed: the generator asks for it by name, and the read follows
the link. Rung 6 refuses, writes nothing and exits 1 (R-024, R-027).
