# The reference course

`tutors-sdk/tutors-reference-course` holds an example of every kind of learning object. Clone it beside
the others:

~~~bash
git clone https://github.com/tutors-sdk/tutors-reference-course.git ~/src/tutors-reference-course
~~~

## Build it with rung 1

~~~bash
cd $LADDER/variants/rung-1-seed
node src/main.ts ~/src/tutors-reference-course out/reference.json
~~~

Rung 1 builds it, and tells you what it skipped:

~~~
skipped topic-03-media/unit-1/notebook-a: this rung does not build this kind
skipped topic-03-media/unit-2-heanet/panelvideo: this rung does not build this kind
...
skipped topic-07-reference/github-1-template-1: this rung does not build this kind
...
wrote /home/you/src/AI-Reference-Projects/tutors/variants/rung-1-seed/out/reference.json: 10 topics
~~~

## Build it with upstream

~~~bash
rm -rf /tmp/ladder-reference
cp -r ~/src/tutors-reference-course /tmp/ladder-reference
cd /tmp/ladder-reference
deno run -A $MONO/packages/jsr/tutors-cli/main.ts build
~~~

## Count the kinds

Save this as `~/ladder-tools/kinds.mjs`. It counts each `type` in two `tutors.json` files:

~~~js
import { readFileSync } from "node:fs";
const count = (lo, out = {}) => { out[lo.type] = (out[lo.type] ?? 0) + 1; (lo.los ?? []).forEach((c) => count(c, out)); return out; };
const [ours, theirs] = process.argv.slice(2).map((f) => count(JSON.parse(readFileSync(f, "utf8"))));
for (const type of [...new Set([...Object.keys(theirs), ...Object.keys(ours)])].sort()) console.log(`${type.padEnd(11)} ${String(ours[type] ?? 0).padStart(3)} ${String(theirs[type] ?? 0).padStart(4)}`);
~~~

~~~bash
node ~/ladder-tools/kinds.mjs $LADDER/variants/rung-1-seed/out/reference.json json/tutors.json
~~~
