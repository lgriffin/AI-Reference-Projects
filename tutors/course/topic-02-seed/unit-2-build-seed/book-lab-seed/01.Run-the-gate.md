# Run the gate

Set two shell variables for the rest of the lab. Change the paths to where you cloned the repositories in
the Orientation lab.

~~~bash
export LADDER=~/src/AI-Reference-Projects/tutors
export MONO=~/src/tutors-mono-repo
cd $LADDER/variants/rung-1-seed
~~~

Rung 1 needs no install. Run its Single Gate:

~~~bash
npm test
~~~

The end of the output:

~~~

# suites 0

# fail 0
~~~

## Read before you run anything else

Open the three files in `src/` and read them whole. They are about 220 lines together. That is the Worked
Slice: the whole capability, small enough to hold in your head.

| File | Read it for |
| --- | --- |
| `src/model.ts` | the `Lo` union, `preOrder`, `folderKinds` |
| `src/course-builder.ts` | `folderKind`, `readMarkdown`, `buildLab`, the `switch` in `buildLo` |
| `src/main.ts` | the only code that touches `process` |

Then read `AGENTS.md` and `RUNG.md`. If you work with a coding agent, ask it to read them first, too.
