# Build the fixture

The shared fixture is a small, compliant course that every rung is tested against.

~~~bash
node src/main.ts ../fixtures/ladder-sample-course out/tutors.json
~~~

~~~
wrote /home/you/src/AI-Reference-Projects/tutors/variants/rung-1-seed/out/tutors.json: 2 topics
~~~

`out/` is in `.gitignore`. Open `out/tutors.json` and find:

- the course's `title` and `summary`, from `course.md`
- `unit-1-lab`, whose `route` ends in `/topic-02-practice/`: a unit routes to its topic
- the lab `book-1-first-lab`, titled `Lab-01-First-Steps`, with three `step` objects
- `web-1-tutors`, whose `route` is `https://tutors.dev`, the first line of its `weburl`
- the talk `talk-1-welcome`, whose `contentMd` is the Marp deck, not `talk.md`

## A tool to read trees

`tutors.json` is long. Save this small script outside the repository, for example as `~/ladder-tools/outline.mjs`.
It prints two course trees side by side and marks each line `=` or `!`:

~~~js
import { readFileSync } from "node:fs";
const outline = (lo, depth = 0) => [`${"  ".repeat(depth)}${lo.type} ${lo.id}: ${lo.title}`, ...(lo.los ?? []).flatMap((c) => outline(c, depth + 1))];
const [a, b] = process.argv.slice(2).map((f) => outline(JSON.parse(readFileSync(f, "utf8"))));
const width = Math.max(...a.map((l) => l.length));
for (let i = 0; i < Math.max(a.length, b.length); i++) console.log(`${(a[i] ?? "").padEnd(width)} ${a[i] === b[i] ? "=" : "!"} ${b[i] ?? ""}`);
~~~

Compare your output with the oracle that upstream wrote for the same folder:

~~~bash
node ~/ladder-tools/outline.mjs out/tutors.json ../fixtures/ladder-sample-course.tutors.json
~~~

`talk-1` by name. That is `preOrder` (talk 4, note 8).
