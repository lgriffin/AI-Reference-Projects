# Objectives

Run the rung 1 generator, read what it writes, and hold it up against the real one. You will build the
shared fixture and the Tutors reference course with both generators, compare them line by line, break the
exhaustive `switch` on purpose to watch L5 and L3 catch it, and then experiment on the upstream generator
and `tutors-cli`.

By the end of this lab you will have:

- run the Single Gate of `variants/rung-1-seed` and read its three source files
- built the fixture with rung 1 and with upstream `tutors build`, and shown the outlines are identical
- built the reference course with both, and named every kind rung 1 skips
- seen the type checker and the test suite catch a missing `case`
- triggered and read an upstream rule failure, and found an upstream generator crash

You need the tools from the Orientation lab: Node.js 22.18 or later, Deno 2, Git, and clones of
`tutors-mono-repo` and `AI-Reference-Projects`. Allow about ninety minutes.
