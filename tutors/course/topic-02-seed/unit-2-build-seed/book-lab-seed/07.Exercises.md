# Exercises

## Exercise 1: an empty descriptor

Make a copy of the fixture in which `note-1-reading/note.md` is empty. Build it with rung 1 and with upstream.
Do the `title`, `summary` and `contentMd` agree? Which upstream rule warns about it (`validate`)?

## Exercise 2: two markdown files

Put a second file, `a-first.md`, in `note-1-reading`, starting `# A first`. Which file gives the note its
title, with rung 1 and with upstream? Find the line in each that decides. (Hint: both sort the folder.)

## Exercise 3: a lab without `img/main.png`

Delete `book-1-first-lab/img` in a copy of the fixture. What is the lab's `title` now, with each generator?
Explain it from `buildLab` in both.

## Exercise 4: a new field

Rung 1 does not write `frontMatter`. Without adding a dependency, could it? Read `stripFrontMatter`, then
the `front-matter` package's behaviour in upstream `buildTalk`. Write down what you would need to parse,
and why the ladder waits for a later rung. Do not change the fence.

## Exercise 5: ask an agent, and read the fence

Ask a coding agent, on rung 1, to "also generate an HTML index page for the course". Run `npm test` on its
change. Which fence rule fails, and which rung does the message send you to?
