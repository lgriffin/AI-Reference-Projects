# The brief

## What upstream does

A `github` folder looks like a `web` folder, with a different link file:

~~~
topic-07-reference/github-1-template-1/
  github.md       # Github Repo  1, then a one-line summary
  github.png
  githubid        https://github.com/tutors-sdk/tutors
~~~

In `packages/jsr/gen/src/services/course-builder.ts` (tutors-mono-repo `2b96b69`):

~~~ts
function buildGithub(lo: Lo, lr: LearningResource) {
  lo.route = getGitLink(lr);
}
~~~

and in `packages/jsr/gen/src/utils/lr-utils.ts`:

~~~ts
export function getGitLink(lr: LearningResource): string {
  const webLinkFile = getFileWithName(lr, "githubid");
  return readFirstLineFromFile(webLinkFile);
}
~~~

`readFirstLineFromFile` (`packages/jsr/gen/src/utils/file-utils.ts`) returns the first line without a
trailing `\r`, or `""` when there is no file. The type is `Github = Lo & { type: "github" }` in
`packages/jsr/model/src/types/learning-objects.ts`, and `preOrder` gives `github` the order 10: after `web`
(9), before `archive` (11).

## What you change

Work in `variants/rung-1-seed` (or a copy of it; see Submission).

1. Add a `Github` member to the `Lo` union in `src/model.ts`, with `type: "github"`.
2. Run the type checker (`npx tsc -p .` after `npm install --no-save typescript@6 @types/node@22`). Make
   every error it reports go away by adding what it asks for, not by casting.
3. Make the folder prefix `github` build the new kind.
4. Build its `route` from the first line of `githubid`.
5. Run the grading test and the gate.

## What you must not change

- `tests/rung-fence.test.ts`, `tests/conformance.test.ts`, the fixture or its oracle: they are behind the
  Human Boundary. The fixture has no `github` folder, so the conformance test should stay green untouched.
- `tests/assignment/github-kind.test.ts`: its expected values were captured from upstream.
- `package.json`: no dependency. `--no-save` keeps TypeScript out of it.

## Out of scope

Rendering a card for `github` is rung 2's job. `panelvideo` (a route from the `videoid` file, with the
HEANET and Panopto formats) is a harder stretch; see "Going further" in Submission.
