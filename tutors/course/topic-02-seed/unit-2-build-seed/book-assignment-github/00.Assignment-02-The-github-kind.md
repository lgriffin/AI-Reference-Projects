# The github kind

Rung 1 recognises a `github-` folder and skips it. Upstream builds it: a card that links to a repository.
Your task is to add the `github` kind to rung 1, end to end, so that it agrees with upstream for every field
rung 1 builds.

It is a small feature with a big lesson. Watch the type system demand every case as you add the kind, and
notice the one place it cannot help you.

You may work with a coding agent. Ask it to read `AGENTS.md` and `RUNG.md` first, name the rung in your
request, and run the gate before you read its diff. Every line it writes is yours to explain.
