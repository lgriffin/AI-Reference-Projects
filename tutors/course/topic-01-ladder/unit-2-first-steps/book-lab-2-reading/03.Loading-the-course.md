# Loading the course

Open `packages/svelte/course/src/course/services/course.svelte.ts` and find `readCourse`. It calls
`getOrLoadCourse`, which does four things.

1. **Check the cache.** `courseService.courses` is a `Map<string, Course>`. A course is fetched once and
   reused.
2. **Work out the URL.** `determineCourseUrl` in `packages/svelte/course/src/course/services/lo-tree.ts`
   turns the id into a host. A bare id such as `reference-course` becomes
   `https://reference-course.netlify.app/tutors.json`; `localhost:8080` becomes
   `http://localhost:8080/tutors.json`. That is how Lab 1's last step worked.
3. **Fetch `tutors.json`.** The whole course, with its Markdown already inlined.
4. **Decorate the tree.** `decorateCourseTree`, in the same `lo-tree.ts`, walks the plain JSON once and adds
   what the UI needs: a `route` on every learning object, `loIndex` and `topicIndex` for O(1) lookup,
   breadcrumbs, icons, and each composite's `units`, `sides` and `panels`. It builds on helpers in
   `packages/jsr/model/src/utils/lo-utils.ts` and `course-utils.ts`.

The types for every field are in `packages/jsr/model/src/types/learning-objects.ts`. The top-level type is
`Course`. Rung 1 of this course rebuilds a small version of exactly these types.
