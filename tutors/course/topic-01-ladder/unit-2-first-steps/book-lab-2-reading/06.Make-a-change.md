# Make one visible change

Change the icon for every web link in the reader.

1. Open `packages/svelte/themes/src/icons/fluent-icons.ts` and find the entry for `web`.
2. Change it to another icon from the same Fluent set on [Iconify](https://icon-sets.iconify.design/fluent/).
3. Stop `pnpm dev` and start it again, because it builds the UI packages once, at startup.
4. Reload your own course from Lab 1 (`http://localhost:5173/course/localhost:8080`). The web card's icon
   has changed.

Now put it back: `git checkout -- packages/svelte/themes/src/icons/fluent-icons.ts`. This lab is for reading,
not for contributing yet.

## Where the styles come from

`apps/reader/src/app.css` is the only stylesheet the reader imports directly. A theme is a `data-theme`
attribute on `<html>` and a CSS file scoped to it. `packages/svelte/themes/src/styles/dyslexia.css` is a
complete example.
