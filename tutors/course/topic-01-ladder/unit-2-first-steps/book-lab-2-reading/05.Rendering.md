# Rendering the page

Open `packages/svelte/ui-components/src/learning-objects/structure/Composite.svelte`. A course is a composite,
and so is a topic, so the same component renders both. It lays out:

- `SecondaryNavigator` from `@tutors/ui-navigators`: the breadcrumb strip
- `Panels`: talks, videos and notes shown inline
- `Units`: each unit as a bordered box with its own cards
- `Cards`: the loose cards at this level

The layout components are in `packages/svelte/ui-components/src/learning-objects/layout/`:

| File | What to look for |
| --- | --- |
| `Units.svelte` | skips units where every learning object is hidden or locked |
| `Cards.svelte` | filters hidden and locked learning objects with `rbacService.isLoLocked` from `@tutors/rbac` |
| `Card.svelte` | the card itself |

## Inside one card

`Card.svelte` asks `themeService` (`packages/svelte/themes/src/services/themes.svelte.ts`) for a layout, a card
style and a colour, then looks up Tailwind classes in `packages/svelte/themes/src/styles/card-styles.ts`.

It shows the summary through `sanitizeHtml` from `packages/svelte/ui-primitives/src/utils/sanitize.ts`,
because summaries are author-supplied HTML. Rung 6 (Guarded) is about exactly this.

The type icon comes from `Icon.svelte` in `packages/svelte/ui-primitives/src/components/`, through
`themeService.getIcon(type)`, which reads `packages/svelte/themes/src/icons/fluent-icons.ts` by default.
