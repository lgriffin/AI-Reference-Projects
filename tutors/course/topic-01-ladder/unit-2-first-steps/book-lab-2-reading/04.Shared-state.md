# Shared state

`readCourse` finishes by publishing the result into shared state. Open
`packages/svelte/runes/src/index.svelte.ts` in `@tutors/runes`.

`currentCourse`, `currentLo` and their friends live here. Each is a lazily created Svelte 5 rune with a
`.value` getter and setter. Any package can import and read them. That is how a component deep inside
`@tutors/ui-components` knows which course it is in without being passed it as a prop.

If a component seems to get data from nowhere, it is reading one of these.

Rung 4 (Reader) is where you will build runes like these yourself.
