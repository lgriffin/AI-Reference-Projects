# Exercises

## Exercise 1: draw the path

Without looking at section 9 of `docs/COURSE-PAGE-WALKTHROUGH.md`, draw the path from
`/course/reference-course` to one `Card`, naming the package and file at each step. Then compare.

## Exercise 2: follow a lab

Click a lab card in the reader. Using the route table in section 6 of the walkthrough, find the route file,
the `courseService` method and the component that render it. Open each one.

## Exercise 3: follow a talk

This course's talks are Marp decks. Which component renders one? Find it under
`packages/svelte/ui-components/src/learning-objects/content/talk/`.

## Exercise 4: one string

Lab 1 warned about a "Not Found" page. It is a visible string, so section 8 of the walkthrough tells you
where to start looking. Find its English text, then find the same key in one of the other five locales.

## Exercise 5: the drift

Write two sentences for a pull request that would bring section 2 of the walkthrough back in line with
`apps/reader/src/routes/+layout.ts`. Keep them; you will need them at the Summit.
