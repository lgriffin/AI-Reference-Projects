# Objectives

Install the tools the whole course uses, run the real Tutors reader from the mono-repo, then write a tiny
course of your own and prove it is a compliant Tutors course with one command.

By the end of this lab you will have:

- Node.js, pnpm, Deno and Git installed at the versions Tutors expects
- a clone of `tutors-sdk/tutors-mono-repo` serving the reference course on your machine
- a clone of the `AI-Reference-Projects` repository, which holds the ladder's variants and its course checker
- a course folder of your own that passes `tutors/scripts/check-course.sh` with zero errors
- your own course open in your local reader

Allow about an hour. Most of it is downloading.
