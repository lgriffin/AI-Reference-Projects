# Write a tiny course

Make a new folder outside both repositories, for example `~/src/my-course`, and create these files.

~~~
my-course/
  course.md
  properties.yaml
  topic-01-hello/
    topic.md
    note-1-welcome/
      note.md
    web-1-tutors/
      web.md
      weburl
~~~

`course.md`: the first line is the course title.

~~~markdown
# My First Course

A tiny course I wrote while setting up Tutors.
~~~

`properties.yaml`:

~~~yaml
credits: Written by me, on the Tutors Ladder course
~~~

`topic-01-hello/topic.md`:

~~~markdown
# Hello

A first topic, with one note and one link.
~~~

`topic-01-hello/note-1-welcome/note.md`:

~~~markdown
# Welcome

This is my first Tutors note. It is **Markdown**.
~~~

`topic-01-hello/web-1-tutors/web.md` gives the card its title and summary, and `weburl` holds the link and
nothing else:

~~~markdown
Tutors

The home of Tutors.
~~~

~~~
https://tutors.dev
~~~

## Why the folder names matter

The generator reads each folder's kind from its name: `topic-`, `note-`, `web-`. A folder whose name starts
with no kind is left out, silently, along with everything inside it. The next step shows how the validator
catches that.
