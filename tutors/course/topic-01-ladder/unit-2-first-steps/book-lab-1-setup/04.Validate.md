# Validate your course

The ladder keeps one command that says "this is a compliant Tutors course":
`tutors/scripts/check-course.sh`. It is a Single Gate for course content.

## Get the script

Clone the repository that holds the ladder:

~~~bash
git clone https://github.com/lgriffin/AI-Reference-Projects.git
~~~

## Run it

~~~bash
cd AI-Reference-Projects
TUTORS_MONO_REPO=~/src/tutors-mono-repo tutors/scripts/check-course.sh ~/src/my-course
~~~

Change the two paths to where you cloned the mono-repo and where you made your course.

## What `TUTORS_MONO_REPO` is for

The script does not carry its own copy of the Tutors rules. It uses the real ones, from your clone of the
mono-repo:

1. It copies your course into a temporary folder, so your folder is never changed.
2. It runs `packages/jsr/tutors-cli/main.ts validate` from `$TUTORS_MONO_REPO` with Deno. That applies the
   rules in `packages/jsr/course-rules`, the same rules as `tutors validate` and Tutors Studio.
3. If there are no errors, it runs the same CLI's `build`, which calls the real generator and checks that
   `json/tutors.json` was written.

So `TUTORS_MONO_REPO` must point at the folder that contains `packages/jsr/tutors-cli`. If `deno` is not on
your `PATH`, set `DENO=/path/to/deno` too. The first run downloads the generator's packages from JSR.

## What you should see

~~~
== validate (/home/you/src/my-course)
warn  V011 netlify.toml: This course has no netlify.toml, so Netlify won't know how to build and publish it. Add the standard one (tutors validate --fix writes it).
0 errors, 1 warning.
It can be fixed for you: run tutors validate --fix.
== build
----: note-1-welcome : Welcome
----: web-1-tutors : Tutors
tutors: 5.3.0
OK: compliant course, 1408 bytes of tutors.json
~~~

Zero errors: your course is compliant. The V011 warning is fair. To fix it, copy the standard `netlify.toml`
from the template in `packages/jsr/course-rules/src/templates.ts`, or run the upstream fixer in your course
folder: `deno run -A jsr:@tutors/tutors-create validate --fix`.

## Break it on purpose

Rename `note-1-welcome` to `welcome` and run the script again:

~~~
error V002 topic-01-hello/welcome: The folder "welcome" won't appear in your course, nor will anything inside it, because its name doesn't start with a kind Tutors knows (topic, unit, talk, note, lab and so on). Rename it so it starts with the kind of content it holds, like talk-, note- or lab-.
...
1 error, 1 warning. Fix the errors before publishing.
validate: errors found
~~~

The script exits with status 1. That message names the rule (V002), the offender (`welcome`) and the fix
(start the name with its kind). That is level L4, Explained, from the Assertion Ladder. Rename the folder back.
