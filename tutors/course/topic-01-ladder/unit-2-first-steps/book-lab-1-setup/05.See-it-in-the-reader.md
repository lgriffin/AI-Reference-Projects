# See your course in the reader

The check script builds `tutors.json` in a temporary folder and throws it away. To read your course, generate
it in place and serve it to the reader you started in step 2. This is the route CONTRIBUTING.md describes.

In your course folder:

~~~bash
deno run -A ~/src/tutors-mono-repo/packages/jsr/tutors/main.ts
npx http-server json -p 8080 --cors
~~~

The first command is the generator. It writes `json/tutors.json`. The second serves that folder. `--cors`
matters, because the reader fetches `tutors.json` from the browser.

Now open **http://localhost:5173/course/localhost:8080**.

The reader treats `localhost:<port>` as a course host. `determineCourseUrl` in
`packages/svelte/course/src/course/services/lo-tree.ts` turns that id into `http://localhost:8080/tutors.json`.

Add `json/` to a `.gitignore` in your course folder: it is generated.
