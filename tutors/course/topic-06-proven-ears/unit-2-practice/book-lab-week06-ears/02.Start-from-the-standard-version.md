## Rung 3's standard version

The class starts rung 4 from one agreed baseline: rung 3's standard version, the zip in week 5's practice
unit, "Rung 3 (layers): the standard version". Unzip it into a fresh folder:

~~~bash
mkdir -p ~/ladder/week06 && cd ~/ladder/week06
unzip ~/Downloads/rung-3-layers.zip
ls tutors-ladder
~~~

Put rung 4 beside it, from your clone of AI-Reference-Projects, with a Git history so you can undo:

~~~bash
cp -r $LADDER/variants/rung-4-proven tutors-ladder/
cd tutors-ladder/rung-4-proven
git init -q && git add -A && git commit -qm "rung 4, as shipped"
pnpm install
~~~

pnpm prints a warning, `Failed to create bin ... vitest-cucumber`: the package ships without its
command-line tool. The library rung 4 uses is complete; `RUNG.md` says so.
