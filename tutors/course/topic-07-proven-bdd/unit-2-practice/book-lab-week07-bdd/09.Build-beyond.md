# Build beyond (Create)

Pick two. Each starts from the value it adds, and each opens with **Specify first**: a requirement with an id
and a scenario seen red, before code.

1. **Paragraph breaks.** Value: a lecturer's heading straight after a paragraph renders as a heading.
   `markdown.ts` has survivors on `startsBlock`, such as `const startsBlock = () => undefined`. Write the
   smallest unit test in `tests/unit/lite/markdown.test.ts` that kills them (a paragraph line followed, with
   no blank line, by a heading). Rerun Stryker; you should meet a `stale-floor` finding. Raise the floor with
   `--update`, and say why a floor that is never raised is a risk.
2. **An equivalent mutant.** Value: less code to maintain. `IGNORED = new Set(["json", "html",
   "node_modules"])` to `new Set([])` survives. Find a course folder for which the two build different
   courses. If you cannot, delete the set as a refactor, with the whole gate green, and say why in the commit.
3. **`--json-only`.** Value: rung 5's reader needs `tutors.json` without pages. Specify it as last week's
   Optional requirement, with an `@active` and an `@inactive` scenario, then build it in `apps/cli`.
4. **A step-position property for the golden page.** Value: the golden file covers a lab step too. Decide
   whether a step page belongs in `tests/conformance/golden/`, and who should approve regenerating it.
