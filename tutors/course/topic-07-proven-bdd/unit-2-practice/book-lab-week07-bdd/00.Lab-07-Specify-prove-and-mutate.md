# Objectives

Take one new rule through every tier of rung 4, the way every lab from now on begins: **Specify first**.
Write an EARS requirement with an id, a Rule and a scenario, and see them fail before any code exists. Make
it pass, then run Stryker and find that every mutant in your new code survives. Find out why, kill them, and
add a property that can fail. Run upstream's steps, compare your rung 4 with the standard version, build
beyond it, and end with a Kaizen step. Rung 4's assignment follows the lab.

## Learning outcomes

| Outcome | Level | Module | Steps |
| --- | --- | --- | --- |
| Specify first: a requirement, a Rule, a scenario and its steps, seen red before code | Apply, Create | M6 | 2, 3 |
| Explain why a scenario proves a requirement but cannot pin its code under mutation | Analyse | M4, M6 | 5 |
| Write a property with a negative fixture that proves it can fail | Apply | M6 | 6 |
| Judge a suite by its mutation score: survivors, equivalent mutants, floors | Evaluate | M6 | 5 |
| Compare upstream's BDD and mutation set-up with rung 4's | Analyse | M4 | 7 |
| Compare your work with the standard version, and extend the variant | Evaluate, Create | M6 | 8, 9 |

Each step's heading names its Bloom level.

Work in the `tutors-ladder/rung-4-proven` folder from Lab 6. Run `git status`: it should be clean (undo Lab
6's experiments with `git checkout .`). Allow about two hours; Stryker takes about a minute a run.
