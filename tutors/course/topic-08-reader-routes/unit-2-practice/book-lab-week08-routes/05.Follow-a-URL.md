# Follow a URL (Analyse)

Open <http://localhost:5173/topic/ladder-sample-course/topic-02-practice> with the browser's Network tab
open, and reload. One request fetches `tutors.json`. Everything in this table happens around it.

| Step | File (under `apps/reader/src`) | What happens |
| --- | --- | --- |
| 1 | `routes/+layout.ts` | `ssr = false`: this page renders in the browser |
| 2 | `routes/(course-reader)/+layout.svelte` | wraps the page in `TutorsShell`; sets the tab's title; focuses `#main-content` after navigating |
| 3 | `routes/(course-reader)/topic/[courseid]/[...loid]/+page.ts` | the folder matched; `params.courseid` is `ladder-sample-course`; the load calls `requestLo("topic", ...)` |
| 4 | `lib/course/course-service.ts`, `requestLo` | calls `readCourse`, then `findLo`, then checks the kind |
| 5 | `lib/course/course-service.ts`, `readCourse` | cache miss; `courseUrl` checks the id (R-015); `fetch("/courses/ladder-sample-course/tutors.json")`; `isCourse` (R-016) |
| 6 | `lib/course/lo-tree.ts`, `decorateCourseTree` | a copy; ids into routes; `loIndex`; `parents` (R-017) |
| 7 | `lib/course/lo-tree.ts`, `findLo` | `loIndex.get("/topic/ladder-sample-course/topic-02-practice")` |
| 8 | `routes/(course-reader)/found.ts` | the answer holds `found`, so it passes through; a `notFound` would become `error(404, ...)` |
| 9 | `lib/runes/index.svelte.ts` | the load sets `currentCourse.value` and `currentLo.value` |
| 10 | `routes/(course-reader)/topic/[courseid]/[...loid]/+page.svelte` | `<Composite composite={data.topic} />` |
| 11 | `lib/ui-components/structure/Composite.svelte` | breadcrumbs, `h1`, then units, sides and cards |
| 12 | `lib/ui-components/layout/Card.svelte` | the link, title, icon and summary you see |

Open each file as you go. None is longer than a screen. Steps 10 to 12 are next week's subject; this week,
stop at the load.

## Draw it

On paper, draw the twelve steps as boxes in four columns: **routes**, **lib/course**, **lib/runes**,
**ui**. Draw an arrow for each call. Two things should stand out:

- every arrow out of **routes** points into `lib`, and no arrow points back;
- the only arrow that leaves the page (the fetch) starts in one box.

Those are the Reader layering rule and the Loader rule. You will break both in step 8.

## Now click

Click the **Ladder Sample Course** breadcrumb, then the **Basics** topic. Watch the Network tab: no second
request for `tutors.json`. Which line of `readCourse` prevented it, and which requirement does that line
keep?

takes `fetch` as an argument and never touches a global.
