## Run it

The mono-repo needs Node 26.13 or later (`.nvmrc`) and pnpm 11.24 or later (`package.json`,
`packageManager`). From `$MONO`, as `apps/reader/README.md` says:

~~~bash
cd $MONO
pnpm install
cp .env.example .env        # PUBLIC_ANON_MODE=TRUE: no backend needed
pnpm dev
~~~

`pnpm dev` builds `ui-primitives`, `ui-navigators` and `ui-components` first, then serves the reader. Open
<http://localhost:5173/course/reference-course> with the Network tab open: one request for the course's
`tutors.json`, from the host that `determineCourseUrl` worked out.

If you cannot run Node 26, read the files instead. Every path below is in the repository, and the flow does
not need a running server to follow.
