# Start from the standard version, install and run (Apply)

## Start from rung 4's standard version

The class climbs from one agreed baseline. Download the zip in week 7's practice unit, "Rung 4: the standard
version", and unzip it in a new working folder for this rung:

~~~bash
mkdir -p ~/ladder/rung5 && cd ~/ladder/rung5
unzip -q ~/Downloads/rung-4-proven.zip
ls tutors-ladder
~~~

~~~

~~~

Rung 5 is a copy of rung 4 that adds the reader. Put it beside rung 4, from your clone of
AI-Reference-Projects, and give it a Git history:

~~~bash
cp -r $LADDER/variants/rung-5-reader tutors-ladder/
cd tutors-ladder/rung-5-reader
git init -q && git add -A && git commit -qm "rung 5, as shipped"
~~~

Every command in this lab runs from `tutors-ladder/rung-5-reader`, with `../fixtures` and `../rung-4-proven`
beside it.

## Install and run the Single Gate

~~~bash
pnpm install
pnpm test
~~~

The gate is rung 4's, plus two things: `svelte-check` type-checks the reader's components, and the reader's
build runs last. Look for these lines:

~~~
... COMPLETED 321 FILES 0 ERRORS 0 WARNINGS 0 FILES_WITH_PROBLEMS
...
 Test Files  29 passed | 1 skipped (30)
      Tests  409 passed | 6 skipped (415)
...
> Using @sveltejs/adapter-static
Wrote site to "build"
~~~

Run the whole gate before any single tier. Its first part runs `svelte-kit sync`, which writes the
reader's generated `tsconfig`; on a fresh copy, `pnpm test:bdd` by itself fails with
`Failed to load tsconfig '$app/tsconfig'` until the gate (or `pnpm typecheck`) has run once.

Rung 4's gate reported `183 passed | 6 skipped`. All of those still run here. The six skipped tests are
next week's assignment. Write down how long the gate took; you will want the number in the Kaizen step.

## The browser tier

~~~bash
pnpm test:e2e
~~~

This builds the reader, serves `apps/reader/build` on a small file server and drives Chromium from the home
page to a lab step. Expect:

~~~
 Test Files  1 passed (1)
      Tests  3 passed (3)
~~~

If Playwright says no browser is installed, run `pnpm exec playwright install chromium` once.

## Run it

~~~bash
pnpm dev
~~~

~~~
  VITE v8.3.5  ready in ... ms

  ➜  Local:   http://localhost:5173/
~~~

Open <http://localhost:5173/>, press **Open the course**, and click through to the lab. Use the left and
right arrow keys on a lab step. Leave `pnpm dev` running in its own terminal for the rest of the lab.
