# Build beyond (Create)

Start the assignment first; these go further. Pick at least one, and start it from the value it adds: say
which customer (student, lecturer, contributor) it serves. Run `npm test` after every change. Every new piece
of course text on a page gets a case in the escaping test (`AGENTS.md`, "Escaping").

1. **A breadcrumb.** Upstream pages carry a breadcrumb trail. Add one to rung 2's `page`: Home, then the topic,
   then the learning object. Which function needs to know the trail, and how does it get it without reading
   the folder?
2. **The archive download.** Rung 2 names an archive's file but does not link it, because it does not copy
   files. Make `main.ts` copy each archive's `.zip` beside its parent page and the card link to it. Which rule
   in `tests/rung-fence.test.ts` still holds? Which layer, in rung 3's terms, should copy the file?
3. **A table of contents.** Give each heading an `id` made from its text, and put a list of links at the top of
   a note. Is `escapeHtml` enough for an attribute value used as a URL fragment?
4. **Ask an agent, and read the fence.** Ask a coding agent, on rung 2, to "make the lab steps collapsible".
   Run the gate on its change. Which fence rule does it meet, and which rung does the message name? Is
   `<details>` (no script at all) a way to deliver the value inside the fence?
