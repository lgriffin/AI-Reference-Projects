# Objectives

Climb from rung 1 to rung 2. Start from rung 1's standard version, see exactly what rung 2 adds, generate the
website and browse it, and set it beside the site upstream `tutors-lite` writes for the same course. Then break
the two promises rung 2 makes, escaping and exhaustive rendering, read how each is caught, and compare your
work with rung 2's standard version.

## Learning outcomes

| Outcome | Level | Steps |
| --- | --- | --- |
| Explain how rung 2 turns a `Course` into pages, and what it adds to rung 1 | Understand | 2, 3 |
| Explain why escaping comes before any tag, and how the `html` template makes it the default | Understand | 5, 6 |
| Generate, browse and move a static site, and compare it with upstream `tutors-lite` | Apply | 3, 4 |
| Break escaping and exhaustiveness on purpose, and say which level catches each | Analyse | 6, 7 |
| Write the week's rule as an EARS sentence, compare with the standard version, and improve the standard work | Evaluate, Create | 8, 10, 12 |

Each step's heading names its Bloom level. The last two steps are Build beyond (Create) and Kaizen (Evaluate).

You need Node.js 22.18 or later, Deno 2, a browser, your `~/src/tutors-ladder` from weeks 1 and 2, and the
`LADDER`, `MONO` and `SEED` variables. Allow about ninety minutes, then start the assignment, "Markdown
tables".
