# Compare with the standard version (Analyse, Evaluate)

Rung 2 is a one-week rung, so this is also its last week. Before you build beyond it, set your work beside
rung 2's standard version: the zip in this week's practice unit, "Rung 2 (lite): the standard version"
(`rung-2-lite.zip`). It passed its gate and built the sample course before it was written.

~~~bash
rm -rf /tmp/standard-2 && mkdir /tmp/standard-2 && cd /tmp/standard-2
unzip -q ~/Downloads/rung-2-lite.zip
ls tutors-ladder
cd tutors-ladder/rung-2-lite && npm test
~~~

Now compare it with your copy, which holds this week's experiments and, once you have done it, the tables

~~~bash
diff -r --exclude=node_modules --exclude=out --exclude=out-ref --exclude=out-evil /tmp/standard-2/tutors-ladder/rung-2-lite $LITE
cd ~/src/tutors-ladder && git diff --stat HEAD -- rung-2-lite
~~~

## Judge the difference

For each difference, decide whether it is **kept** (the assignment, a Build beyond extension, a test you
added), a **leftover** (a break from steps 6 and 7 you did not restore, an output folder) or a candidate
**improvement to the standard version itself**. Leftovers go. Improvements go into your Kaizen step.

Your rung 2 is now the baseline you carry into week 4, where rung 3 starts from this standard version and
splits it into packages. Delete `/tmp/standard-1` and `/tmp/standard-2` when you are done.
