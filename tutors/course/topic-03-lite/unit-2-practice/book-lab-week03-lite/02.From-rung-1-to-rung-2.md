# From rung 1's standard version to rung 2 (Understand, Apply)

Each rung starts from the standard version of the rung below. For rung 2 that is rung 1's zip, in week 2's
practice unit: "Rung 1 (seed): the standard version" (`rung-1-seed.zip`). Your own `$SEED` holds your
assignment and extensions, so unzip a clean copy to compare against:

~~~bash
rm -rf /tmp/standard-1 && mkdir /tmp/standard-1 && cd /tmp/standard-1 && unzip -q ~/Downloads/rung-1-seed.zip
~~~

Now bring rung 2 into your working folder, beside rung 1 and the fixture, and commit it as its own step:

~~~bash
cp -r $LADDER/variants/rung-2-lite ~/src/tutors-ladder/
cd ~/src/tutors-ladder && git add rung-2-lite && git commit -q -m "Rung 2: start"
export LITE=~/src/tutors-ladder/rung-2-lite
~~~
