## What this week adds

Rung 2 is rung 1, unchanged, plus a renderer:

| New file | Job |
| --- | --- |
| `src/html.ts` | `escapeHtml`, the `html` tagged template, `SafeHtml`, the page layout |
| `src/markdown.ts` | a small Markdown renderer |
| `src/site-builder.ts` | `Course` to pages: which pages exist, how each kind looks |
| `src/main.ts` | now builds, renders, then writes the pages and `tutors.json` |

The fence changes one rule: HTML output is now allowed, and client-side script is refused instead. In the
Tutors value stream, rung 2 adds a second road from the generator to a student's screen, with no reader in
between.
