# Kaizen (Evaluate)

Ten minutes, in your notes.

1. **Name one waste** you met this week. Candidates: *defects* that only a page-level test caught;
   *relearning* (finding the same upstream setting twice); *extra features* (an agent reaching for a Markdown
   library or a script the fence refused, which is overproduction); *waiting* for the upstream build.
2. **Find its root cause.** Ask "why?" two or three times. Stop at something you could change.
3. **Improve the standard work.** This week's standard work is the Single Gate, `AGENTS.md`'s "Escaping"
   section, and the standard version you compared against. Propose one improvement. For example: a test that
   makes a line of `AGENTS.md` unnecessary; a clearer fence message; a short script that runs the gate, builds
   the fixture and lists the pages in one command.

Write it as "I will ... so that ...". If your improvement changes a test, the fence or `AGENTS.md`, write it as
a proposal for a person: those files are behind the Human Boundary.
