# The grading test

The grading test is in the standard version: `$LITE/tests/assignment/markdown-tables.test.ts`. It
is skipped unless you ask for it, and the gate's `tests/*.test.ts` does not reach it.

~~~bash
cd $LITE
LADDER_ASSIGNMENT=1 node --test tests/assignment/*.test.ts
~~~

Before you start, seven of the eight tests fail. AC6 already passes, because today every table is a
paragraph: keep it passing.

~~~
# pass 1
# fail 7
~~~

When you are done: `# pass 8`.

## How it compares

The test removes whitespace between tags, then compares exactly:

~~~ts
/** The renderer's output with whitespace between tags removed. */
const md = (text: string) => renderMarkdown(text).value.replace(/>\s+</g, "><").trim();

test("AC3: colons in the delimiter row align the column", { skip }, () => {
  assert.equal(
    md("| L | C | R |\n|:--|:-:|--:|\n| 1 | 2 | 3 |"),
    '<table><thead><tr><th style="text-align:left">L</th><th style="text-align:center">C</th><th style="text-align:right">R</th></tr></thead>' +
      '<tbody><tr><td style="text-align:left">1</td><td style="text-align:center">2</td><td style="text-align:right">3</td></tr></tbody></table>',
  );
});
~~~

So you may put newlines between your tags or not. The expected strings are markdown-it's output for the same
input, which is what upstream's reader shows.

## The escaping case

AC8 checks the renderer and a whole page:

~~~ts
const evil = "<script>alert(1)</script>";
assert.equal(md(`| ${evil} |\n|---|\n| <img src=x onerror=alert(1)> |`),
  "<table><thead><tr><th>&lt;script&gt;alert(1)&lt;/script&gt;</th></tr></thead><tbody><tr><td>&lt;img src=x onerror=alert(1)&gt;</td></tr></tbody></table>");
...
assert.doesNotMatch(note.html, /<script/, "a table cell reached the page unescaped");
~~~

When you have finished, add a table case to "course text never reaches a page unescaped" in
`tests/site-builder.test.ts` as well, as `AGENTS.md` asks for every new piece of course text on a page.
