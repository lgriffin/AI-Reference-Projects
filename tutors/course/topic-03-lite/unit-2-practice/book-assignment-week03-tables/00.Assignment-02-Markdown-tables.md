# Markdown tables

This is rung 2's coding assignment, assessed at Bloom's **Create** level. Work in your copy, `$LITE`.

Tutors courses use tables: kinds and prefixes, commands and what they do, marking schemes. Rung 2 shows a
table as a paragraph of pipes. Your task is to teach `src/markdown.ts` the GitHub Flavored Markdown table:
header, delimiter row, body rows, alignment, inline Markdown in cells, and every cell escaped.

The oracle is markdown-it, upstream's renderer: the grading test's expected HTML is what markdown-it writes
for the same input, with the newlines between tags removed.

You may work with a coding agent. The fence still forbids a Markdown library: if your agent reaches for
one, the gate will tell it which rung that belongs to.
