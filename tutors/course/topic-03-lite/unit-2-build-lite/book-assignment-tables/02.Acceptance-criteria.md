# Acceptance criteria

EARS sentences, one "shall" each. "The renderer" is `renderMarkdown` in `src/markdown.ts`.

| Id | Criterion |
| --- | --- |
| AC1 | When a line with a `\|` is followed by a delimiter row with the same number of cells, the renderer shall render the two lines and the body rows after them as one `<table>` with a `<thead>` and a `<tbody>`. |
| AC2 | The renderer shall accept table rows with or without leading and trailing pipes, and shall trim each cell. |
| AC3 | Where a delimiter cell starts or ends with `:`, the renderer shall add `style="text-align:left"`, `"center"` or `"right"` to every `<th>` and `<td>` in that column. |
| AC4 | If a body row has fewer cells than the header, then the renderer shall add empty cells; if a table has no body rows, then the renderer shall omit `<tbody>`. |
| AC5 | The renderer shall render each cell as inline Markdown: code spans, emphasis, links and images. |
| AC6 | If the line after a candidate header row is not a delimiter row with one cell per header cell, then the renderer shall render the lines as a paragraph, as it does today. |
| AC7 | The renderer shall end a table at a blank line or at a line that contains no `\|`. |
| AC8 | The renderer shall escape every character of every cell, so that no tag or attribute from course text reaches a page. |
| AC9 | When `npm test` is run, the gate shall pass, with the Rung Fence and the escaping tests unchanged. |

AC1 to AC8 are checked by the grading test, one test each. AC9 is the Single Gate.
