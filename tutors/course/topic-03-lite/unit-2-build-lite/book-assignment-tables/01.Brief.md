# The brief

## What a table looks like

~~~markdown
| Kind | Prefix | Order |
|:-----|:------:|------:|
| talk | `talk-` | 4 |
| lab  | `book-` | 7 |
~~~

A table is:

1. a **header row**: a line with at least one `|`;
2. a **delimiter row** right after it, with exactly one cell per header cell, each cell made of `-`
   with an optional `:` at either end;
3. zero or more **body rows**: the following lines that contain a `|`, up to a blank line or a line with no
   `|`.

The outer pipes are optional: `a | b` and `| a | b |` are the same row. Cells are trimmed.

## What to render

~~~html
<table><thead><tr><th style="text-align:left">Kind</th><th style="text-align:center">Prefix</th>...</tr></thead>
<tbody><tr><td style="text-align:left">talk</td><td style="text-align:center"><code>talk-</code></td>...</tr>...</tbody></table>
~~~

- `:--` is left, `:-:` center, `--:` right; plain `---` adds no `style` attribute.
- A body row with fewer cells than the header gets empty cells. A table with no body rows has no `<tbody>`.
- Each cell is inline Markdown: code spans, emphasis, links, images, as `renderInline` already does.
- Every cell is escaped. `renderInline` escapes for you; never build a cell from raw text.

## Where it goes

Only `src/markdown.ts`. Add a branch to the block loop in `renderMarkdown`, before the paragraph branch:
it must recognise a table from **two** lines (the header and the delimiter row) and consume the body rows.
Small helpers (split a row into cells, read the alignments) are welcome.

Add your own cases to `tests/markdown.test.ts` too. The grading test is the minimum.

## What you must not change

- `tests/assignment/markdown-tables.test.ts`, `tests/rung-fence.test.ts`, the escaping tests,
  `tests/conformance.test.ts`, the fixture, `package.json`.
- `new SafeHtml(...)` stays in `src/html.ts` and `src/markdown.ts` only.

## Out of scope

Escaped pipes (`\|`) inside cells, tables that interrupt a paragraph without a blank line before them, and
cells with more columns than the header (GFM drops the extras). Try them under "Going further".
