# Exercises

## Exercise 1: a heading in a list

What does rung 2 render for `- # not a heading`? What does CommonMark say? Write the test you would add to
`tests/markdown.test.ts`, run it, and decide whether to change the renderer or keep the test as a record of
the difference.

## Exercise 2: a breadcrumb

Upstream pages carry a breadcrumb trail. Add one to rung 2's `page`: Home, then the topic, then the
learning object. Which function needs to know the trail, and how does it get it without reading the folder?
Every title in the trail is course text: add it to the escaping test.

## Exercise 3: the archive download

Rung 2 names an archive's file but does not link it, because it does not copy files. Change `main.ts` to
copy each archive's `.zip` beside its parent page and change the card to link it. Which rule in
`tests/rung-fence.test.ts` still holds? Which layer (in rung 3's terms) should copy the file?

## Exercise 4: a table of contents

Upstream adds anchors to headings (`markdown-it-anchor`) and a table of contents. Add an `id` to each heading
in `renderMarkdown`, made from its text, and a list of links at the top of a note. How do you make an `id`
safe? Is `escapeHtml` enough for an attribute value used as a fragment?

## Exercise 5: ask an agent

Ask a coding agent, on rung 2, to "make the lab steps collapsible". Run the gate on its change. Which fence
rule does it meet, and which rung does the message name?
