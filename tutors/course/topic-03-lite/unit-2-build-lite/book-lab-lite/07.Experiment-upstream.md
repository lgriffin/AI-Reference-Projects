# Experiment on upstream

Work in `/tmp/ladder-fixture`, never in the clone.

## 1. The command as a testable function

Open `packages/jsr/tutors-lite/src/run.ts`. `runTutorsLite` takes a `LiteGenerator`: the three generator
calls it makes, "injectable so a test can stand in for any one of them". Then open
`packages/jsr/tutors-lite/test/run.test.ts` and find a test that stands in for `generateStaticCourse`.
Rung 2's `main.ts` is not injectable. Rung 3 makes it so, with a port. Which design does rung 3 choose, and
why might it be different from upstream's?

## 2. The layout

Open `packages/jsr/gen/src/templates/vento/layouts/main.vto` and rung 2's `page` in `src/html.ts`. List what
upstream's layout loads that rung 2's does not (stylesheets, scripts, fonts). Which of them would rung 2's
fence refuse, and with which message?

## 3. A lab with step navigation

Open `packages/jsr/gen/src/templates/vento/Lab.vto`. Find where it marks the current step in bold, and where
it builds the Previous and Next links. Compare with `labPages`. Upstream's mobile bar links to
`prevStep.shortTitle` with a special case for the first step. Does rung 2 need that special case? Why not?

## 4. Tables in a real course

Find a Markdown table in the reference course:

~~~bash
grep -rl '^|' ~/src/tutors-reference-course --include=*.md | head
~~~

Build that page with both generators and compare. That is the assignment.
