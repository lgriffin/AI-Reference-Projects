# Compare with tutors-lite

Build the same course with upstream. `tutors website` runs `@tutors/tutors-lite` and writes `html/` in the
current folder:

~~~bash
rm -rf /tmp/ladder-fixture
cp -r $LADDER/variants/fixtures/ladder-sample-course /tmp/ladder-fixture
cd /tmp/ladder-fixture
deno run -A $MONO/packages/jsr/tutors-cli/main.ts website
~~~

The log ends `tutors-lite: 5.3.0`. Open `/tmp/ladder-fixture/html/index.html` in your browser and click the
same path as before.

## Which pages exist

~~~bash
diff <(cd $LADDER/variants/rung-2-lite/out && find . -name '*.html' | sort) <(cd html && find . -name '*.html' | sort)
~~~

Every rung 2 page exists upstream at the same path. Upstream adds one **wall** per kind: a page listing every
talk, every lab, and so on. Find `emitWalls` in `packages/jsr/gen/src/services/course-emitter.ts`.

## The reference course

Do the same for the reference course (cloned in the Seed lab):

~~~bash
cd $LADDER/variants/rung-2-lite
node src/main.ts ~/src/tutors-reference-course out-ref
rm -rf /tmp/ladder-reference && cp -r ~/src/tutors-reference-course /tmp/ladder-reference
cd /tmp/ladder-reference && deno run -A $MONO/packages/jsr/tutors-cli/main.ts website
diff <(cd $LADDER/variants/rung-2-lite/out-ref && find . -name '*.html' | sort) <(cd html && find . -name '*.html' | sort)
~~~

Rung 2 writes 108 pages, upstream 122. The difference is the walls (now including `github.html`,
`notebook.html`, `podcast.html`, `quiz.html` and `tutorial.html`), and the pages for kinds rung 2 does not
build: three `tutorial` pages and one `panelnote` page. Which upstream function emits a tutorial page?

`out-ref/` is not in `.gitignore`. Delete it when you are done.
