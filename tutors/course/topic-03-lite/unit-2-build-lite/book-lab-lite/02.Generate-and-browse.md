## Browse it

Open `out/index.html` in your browser straight from disk (`file://`). Click through:

1. **Basics**: the topic page shows the unit *Introduction* and the side *Resources* as groups of cards.
   There is no page for a unit: its cards live on its topic's page.
2. **Welcome**: a talk, one bordered section per slide. The deck is split on `---` lines.
3. **Reading Guide**: a note, with a numbered list, bold, emphasis, a link and a code block.
4. **Practice**, then **Lab-01-First-Steps**: the step list, Previous and Next.
5. The **Tutors** card is a web link: it leaves the site.

Every link worked from `file://`, with no server. Look at the source of `Setup.html`:

~~~html
<nav><a href="../../../index.html">Home</a><a href="../../../topic-02-practice/index.html">Up</a></nav>
~~~

Count the `../`: three, because the page is three folders deep. That is `relativeHref`.

## Move it

Copy the whole folder somewhere else and open it again. Zip it and unzip it. It still works. Then serve it,
as a static host would:

~~~bash
python3 -m http.server --directory out 8000
~~~

and open **http://localhost:8000**. Same site. Stop the server with Ctrl+C.
