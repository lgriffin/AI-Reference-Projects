# Objectives

Generate the rung 2 website, browse it, and set it beside the site upstream `tutors-lite` writes for the
same course. Then break the two promises rung 2 makes, escaping and exhaustive rendering, and read how each
is caught.

By the end of this lab you will have:

- run rung 2's Single Gate and read `src/html.ts`, `src/markdown.ts` and `src/site-builder.ts`
- generated and browsed the fixture's site, and followed its relative links
- built the same course with upstream `tutors website`, and named every page one has that the other lacks
- seen the same note rendered with raw HTML upstream and escaped by rung 2
- broken escaping and exhaustiveness on purpose, and read the failures

You need Node.js 22.18 or later, Deno 2, a browser, and the `LADDER` and `MONO` variables from the Seed lab.
Allow about ninety minutes.
