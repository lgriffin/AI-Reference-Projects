# A validate package

Upstream checks courses with `packages/jsr/course-rules`: twenty-one rules, read through a
`FileSystemPort`, run by the CLI, by Tutors Studio and by the reader's wizard. Your task is to start the
same thing in rung 3: a new workspace package, `@ladder/validate`, with two of upstream's rules, V001 and
V003, wired into the command line as `validate <courseFolder>`.

The code is short. The lesson is where it goes. You decide which layer the package sits in, what it may
import, and you change the architecture test and the fence to say so. Those are Human Boundary changes:
you make them, not your agent.
