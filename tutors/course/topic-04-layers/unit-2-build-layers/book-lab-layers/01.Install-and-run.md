# Install and run

Rung 3 pins pnpm in its `package.json` (`"packageManager": "pnpm@10.28.0"`). Install that version if you
do not have pnpm 10:

~~~bash
npm install --global pnpm@10.28.0
cd $LADDER/variants/rung-3-layers
pnpm install
~~~

The install brings two dev dependencies, `typescript` and `@types/node`, and links the four workspace
packages to each other. Then run the Single Gate:

~~~bash
pnpm test
~~~

It first runs `pnpm typecheck` (one `tsc -p` per package, then the tests' project), then every suite:

~~~
# tests 76
# suites 15
# pass 69
# fail 0
# cancelled 0
# skipped 7
~~~

The seven skipped tests are the assignment's grading test, waiting for you. Then run the tools:

~~~bash
pnpm start ../fixtures/ladder-sample-course out
~~~

~~~
