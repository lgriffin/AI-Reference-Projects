# Objectives

Install the rung 3 workspace, walk its packages, then break every architecture rule on purpose and read
what each failure tells you. Make the test double lie and watch the contract catch it. Finally, explore how
tutors-mono-repo keeps its own layers.

By the end of this lab you will have:

- installed a pnpm workspace and run its Single Gate, compiler included
- traced how `@ladder/gen` reaches `@ladder/model` through `workspace:*` links
- broken the Layering, Closure, Port, Model and Package boundary rules, and read each teaching failure
- seen the compiler and the architecture test catch the same mistake independently
- made `MemoryFileSystem` lie, added a new adapter, and watched the Honest Double rule and contract react
- read upstream's dependency-cruiser rules, negative fixtures and known-violations ratchet

You need Node.js 22.18 or later, pnpm 10, and the `LADDER` and `MONO` variables from the Seed lab. Allow
about two hours. Every break is undone with `git checkout` before the next.
