# Objectives

Trace rung 3's port from the composition root to the core, break it, make its test double lie, add an
adapter, and turn one red build into an improvement with Five Whys. Then compare your rung 3 with the
standard version, build beyond it, and end with a Kaizen step. The assignment, a validate package, follows
this lab.

## Learning outcomes

| Outcome | Level | Steps |
| --- | --- | --- |
| Explain how the port, the two adapters and the composition root fit together | Understand | 2 |
| Diagnose a Port rule failure and explain why the compiler and the test each catch what they do | Analyse | 3 |
| Judge whether a test double is honest by running one contract against it and the real adapter | Evaluate | 4, 5 |
| Use Five Whys to trace a red build to a root cause in the standard work | Analyse, Evaluate | 6 |
| Write the port rule as an informal EARS sentence | Create | 7 |
| Compare upstream's port, adapters and architecture tests with rung 3's | Analyse | 8 |
| Compare your work with the standard version, and extend the variant | Evaluate, Create | 9, 10 |

Each step's heading names its Bloom level.

Work in the `tutors-ladder/rung-3-layers` folder you set up in Lab 4, with `../fixtures` beside it. Run
`git status` first: it should be clean. Allow about two hours. Every break is undone with `git checkout`.
