# Make the double lie (Analyse, Evaluate)

`gen`'s fast tests all use `MemoryFileSystem`. If it lies, they lie too. Make it lie on purpose: in
`packages/gen/src/memory-file-system.ts`, change the root case of `exists`:

~~~ts
    if (target === "") return Promise.resolve(false);
~~~

~~~bash
node --test apps/cli/tests/file-system-port.contract.test.ts
~~~

~~~
# Subtest: FileSystemPort contract: NodeFileSystem
# Subtest: FileSystemPort contract: MemoryFileSystem
    not ok 3 - exists is true for the root, a folder and a file, and false otherwise
      expected: true
      actual: false
not ok 2 - FileSystemPort contract: MemoryFileSystem
# pass 5
# fail 1
~~~

The same assertion passed for `NodeFileSystem` and failed for `MemoryFileSystem`. Without the contract,
`gen`'s memory-based tests could have gone on passing.

## Judge the contract

Read the three contract tests. Find one way `MemoryFileSystem` could still lie that **no** contract test
would catch. (Try: what does `list` return for a folder that does not exist, on each adapter?) Write the
missing assertion in your notes; you will see in week 6 that rung 4 added exactly such a case.
