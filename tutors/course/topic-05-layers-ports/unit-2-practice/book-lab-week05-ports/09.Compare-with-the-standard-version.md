# Compare with the standard version (Evaluate)

Rung 3's completed code ships as a zip, the **standard version**: the agreed baseline the whole class takes
into rung 4. It is in this week's practice unit, "Rung 3 (layers): the standard version". Do this step after the
assignment, so you have work of your own to compare.

## Download, unzip, run

Unzip it into a folder of its own, so it does not overwrite your work:

~~~bash
mkdir -p ~/ladder/standard && cd ~/ladder/standard
unzip ~/Downloads/rung-3-layers.zip
ls tutors-ladder
cd tutors-ladder/rung-3-layers
pnpm install
pnpm test
~~~

did not mean? Anything in the last group, put back. Then answer:
