# Kaizen (Evaluate)

Ten minutes, as every week.

## Name one waste

Candidates from this week:

- **Relearning.** A failure message you had to look up elsewhere to understand. What did it lack?
- **Handoffs.** If `gen` read `node:fs` directly, who would have to redo work for Studio or the reader?
- **Defects.** The lie in step 4 was caught by the contract. Which lie would not be (your answer to step 4)?
- **Waiting.** How long did you wait for the gate? Did you run the whole gate when one file would do?

## Find its root cause

Use your Five Whys from step 6, or do a short one now.

## Improve the standard work

Make or propose one change: a line in `AGENTS.md`, a sentence in a header comment, a new assertion in the
contract, or a habit of your own (for example "run the one test file first, then the gate"). Record it in
your learning log with this week's date.

This is the end of rung 3. Before week 6, re-read your Kaizen notes from weeks 1 to 5: is there a waste
that keeps coming back?
