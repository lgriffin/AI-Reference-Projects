# Acceptance criteria

EARS sentences, one "shall" each. Each criterion maps to a week 5 (or week 4) outcome and to the module
outcomes in `course.md` (A3 assesses M3, M4 and M5). All are assessed at **Create**, because together they
are a package you design and build.

| Id | Criterion | Week 5 outcome | Module outcome |
| --- | --- | --- | --- |
| AC1 | The workspace shall have a package `@ladder/validate` in `packages/validate`, exporting `./src/index.ts`, depending only on `@ladder/model` and `@ladder/gen` as `workspace:*`, and compiled with no Node types. | Create a package with its own layer | M3, M5 |
| AC2 | The Single Gate shall type-check `packages/validate`, the architecture test shall place `@ladder/validate` in `LAYERS` with neither `lite` nor `cli` in its allowed imports, `@ladder/cli` shall be allowed to import it, and the Rung Fence shall check it. | Create a package with its own layer; Evaluate where code belongs | M5 |
| AC3 | If the course root has no `course.md`, then `validate` shall return exactly one V001 error, at path `""`, with upstream's message. | Understand the port | M3 |
| AC4 | When a folder whose name starts with `topic`, `unit` or `side` holds no `.md` file, `validate` shall return one V003 error at that folder's path, with upstream's message for its kind, at any depth. | Understand the port | M3 |
| AC5 | `validate` shall not report V003 for folders of no kind or for simple kinds such as `talk`. | Understand the port | M3 |
| AC6 | When run on the shared fixture through `NodeFileSystem`, `validate` shall return no findings. | Judge a double's honesty (real adapter) | M4 |
| AC7 | When `validate <courseFolder>` is run, the command shall print each finding as `<severity> <rule> <path>: <message>` and exit with status 1 if there is an error, and 0 otherwise. | Understand the composition root | M3, M5 |
| AC8 | While the new package is in place, every architecture rule shall pass: it imports no `node:` module, reaches no other package by a relative path, and its `package.json` declares exactly what it imports. | Analyse a Port rule failure | M4, M5 |
| AC9 | When `pnpm test` is run, the gate shall pass. | all | M3, M4, M5 |

AC1 to AC7 are checked by the grading test. AC8 is the architecture test you extended. AC9 is the gate.
