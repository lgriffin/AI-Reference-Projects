# Rung 3 exit criteria

Rung 3 ends here. Before week 6, check each line. The first five are about understanding; the last three
are evidence you can show.

| You can | Level | Evidence |
| --- | --- | --- |
| explain every line of `pnpm test`'s summary in rung 3, skipped tests included | Understand | Lab 4, step 2 |
| name the six architecture rules and the Lean waste each removes | Understand | the two reading notes |
| break the Port rule and read both walls, the compiler's and the test's | Analyse | Lab 5, step 3 |
| explain why one contract against two adapters keeps a double honest | Evaluate | Lab 5, step 4 |
| trace a red build to a root cause in the standard work with Five Whys | Evaluate | Lab 5, step 6 |
| pass the grading test, `# pass 7`, with `pnpm test` green | Create | this assignment |
| show the Human Boundary changes in a commit of their own, before the code | Create | your history |
| compare your rung 3 with the standard version and say what yours adds | Evaluate | Lab 5, step 9 |

If a line is not yet true, it is the first thing to do in week 6. Rung 4 starts from rung 3's standard
version, so you lose nothing by climbing: your `@ladder/validate` stays in your own copy, ready to carry
forward when you choose.
