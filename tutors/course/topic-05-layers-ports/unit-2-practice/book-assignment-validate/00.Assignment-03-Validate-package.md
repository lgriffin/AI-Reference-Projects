# Assignment 3: a validate package

Rung 3's coding assignment (A3 in `course.md`), assessed at the **Create** level of Bloom's taxonomy. It
assesses module outcomes M3 (extend a variant with a new capability), M4 (diagnose why a check fails) and
M5 (restructure into layers and ports, and justify where each rule belongs).

Upstream checks courses with `packages/jsr/course-rules`: rules read through a `FileSystemPort` and run by
the CLI, by Tutors Studio and by the reader's wizard. Your task is to start the same thing in rung 3: a new
workspace package, `@ladder/validate`, with two of upstream's rules, V001 and V003, wired into the command
line as `validate <courseFolder>`.

The code is short. The lesson is where it goes. You decide which layer the package sits in and what it may
import, and you change the architecture test and the fence to say so. Those are Human Boundary changes: you
make them, not your agent.
