# Objectives

Cut a release of the rung 7 variant from start to finish: Conventional Commits, a version bump, a
changelog section, the claims check, the SLO check, a container build (or a dry run), and the readiness
A3. Then read how tutors-mono-repo does the same thing at full size: its release SOP, its release harness
and the harness's A3 and scoreboard.

By the end of this lab you will have:

- run rung 7's Single Gate and read what the fence lets it do that rung 3 could not
- made two Conventional Commits in a scratch repository and derived version 1.1.0 and its changelog from them
- broken a release claim and an SLO on purpose, and read how each failure teaches
- built and smoke-checked the image, or seen why the check skipped
- read a readiness A3 for your release, then tagged it yourself
- traced each of your steps to its counterpart in upstream's `release/SOP.md`

You need Node.js 22.18 or later, pnpm, Git, and the `LADDER` and `MONO` variables from the Seed lab. Docker
is optional. Allow about ninety minutes.
