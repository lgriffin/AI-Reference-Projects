# Build and smoke the container

Read the `Dockerfile` first. Two stages: Node builds the fixture site, BusyBox serves it. Find the two
digests, the `USER` line and the labels.

## Without Docker

See exactly what the smoke check would run:

~~~bash
pnpm container:smoke --dry-run
~~~

~~~
docker build -q -f Dockerfile -t tutors-ladder:1.1.0 --build-arg VERSION=1.1.0 --build-arg GIT_SHA=<your commit> ..
docker run -d --rm --read-only --cap-drop ALL --security-opt no-new-privileges -p 127.0.0.1::8080 tutors-ladder:1.1.0
container smoke: SKIPPED: dry run: commands printed, none run
~~~

The build context is `..`, the folder that holds both `rung-7-shipped` and `fixtures`. With Docker installed
but no daemon running, the real command skips and says why, and the A3 will say "not run":

~~~
container smoke: SKIPPED: docker is installed but no daemon answers (...). The image was not built or checked; run this where Docker runs (CI does), or use --dry-run to see the commands.
~~~

## With Docker

~~~bash
pnpm container:smoke
~~~

~~~
container smoke: PASSED: every check passed
  ok user is 10001:10001, not root
  ok revision label is 7d37fc0
  ok /version.json answers 1.1.0 at 7d37fc0
  ok /index.html is served
  ok /tutors.json is served and parses
~~~

If Docker Hub refuses the pull with a rate limit, pull the same digests from a mirror:

~~~bash
LADDER_REGISTRY=mirror.gcr.io/library pnpm container:smoke
~~~

The digest still decides the bytes: a mirror that served different ones would fail the pull.

## Try it as a person would

~~~bash
docker run --rm --read-only --cap-drop ALL -p 127.0.0.1:8080:8080 tutors-ladder:1.1.0
~~~

Open `http://127.0.0.1:8080/` and `http://127.0.0.1:8080/version.json`. Then
`docker image inspect tutors-ladder:1.1.0 --format '{{.Size}} {{.Config.User}}'`: about 7 MB, user 10001.

## Break it

Change `USER 10001:10001` to `USER 0` in the `Dockerfile` and run `pnpm test`. Which test fails, and what
does its message say about why? Then remove the digest from one `FROM` line and run it again. Put both back
with `git checkout Dockerfile`.
