# Every page within budget

Rung 7 keeps a budget for the whole site, but a learner never downloads the whole site. They open one
page. Your task is to add a service level objective for the largest page, a check that fails with a
teaching message when a page is over it, and a release claim that promises it, with a test as evidence.

This is the release discipline in miniature: a number written down, a check that holds it, and a promise
that cannot be made without evidence.

You may work with a coding agent. The fence still holds: no new dependency, and the scripts never import
the packages they judge.
