# Layers: trace and break (Analyse)

## Trace one card

Open <http://localhost:5173/topic/ladder-sample-course/topic-01-basics> and inspect the **Welcome** card in
the browser's developer tools. Then follow it inwards through the files, noting each file's layer:

| File (under `apps/reader/src/lib`) | Layer | What it adds |
| --- | --- | --- |
| `ui-components/structure/Composite.svelte` | components | breadcrumbs, the `h1`, units and sides |
| `ui-navigators/SecondaryNavigator.svelte` | navigators | the breadcrumb trail, from `breadCrumbs` |
| `ui-components/layout/Units.svelte` | components | a box and a heading per unit |
| `ui-components/layout/Cards.svelte` | components | the grid; turns each `Lo` into `cardDetails` |
| `ui-components/layout/Card.svelte` | components | the link, the title, the hidden kind |
| `ui-primitives/Icon.svelte`, `lo-colours.ts` | primitives | the icon and the colour for the kind |

Every import in that chain points down the table of layers in `tests/architecture/reader-layers.test.ts`.
In the inspector, find `data-lo-type="talk"` and the visually hidden text "talk". Who needs each?

Now break two rules. For each: make the change, predict the failing test, run it, read the message, undo.

## 1. A primitive that reaches for data

In `apps/reader/src/lib/ui-primitives/Icon.svelte`, add inside the first `<script>`:

~~~ts
  import { currentLo } from "../runes/index.svelte.ts";
~~~

~~~bash
pnpm exec vitest run tests/architecture
~~~

~~~
AssertionError: Reader layering rule: lib/ui-primitives may import only [nothing else in the reader],
because primitives (Icon, Markdown) are the smallest pieces; like upstream's ui-primitives they import no
data, so any layer above can use them. Pass what you need down as a prop, or move the code to the layer
that may import it (README.md, The reader).
  apps/reader/src/lib/ui-primitives/Icon.svelte imports "../runes/index.svelte.ts" (lib/runes)
~~~

Compare upstream's rule and its reason:

~~~bash
grep -n "ui-primitives-no-data-features" -A3 $MONO/.dependency-cruiser.cjs
~~~

## 2. Raw HTML in a card

In `apps/reader/src/lib/ui-components/layout/Card.svelte`, change `<p>{cardDetails.summary}</p>` to
`<p>{@html cardDetails.summary}</p>`.

~~~bash
pnpm exec vitest run tests/architecture
~~~

~~~
AssertionError: Raw HTML rule: {@html} bypasses Svelte's escaping, so the reader uses it in one place,
lib/ui-primitives/Markdown.svelte, on what renderMarkdown from @ladder/lite returns (it escapes first).
Show course text with {text}, which Svelte escapes, or as <Markdown markdown={...} />. Sanitising author
HTML arrives in rung 6 (Guarded).
  apps/reader/src/lib/ui-components/layout/Card.svelte
~~~

A summary is text a lecturer wrote. With `{@html}` a summary of `<img src=x onerror=...>` would run in every
student's browser. Week 10 is about exactly this.

## 3. A dependency from a later rung

Add `"tailwindcss": "^4.3.3"` to `devDependencies` in `apps/reader/package.json` (do not install it).

~~~bash
pnpm exec vitest run tests/rung-fence.test.ts
~~~

~~~
AssertionError: Rung Fence, rung 5 (Reader): apps/reader/package.json declares "tailwindcss" in
devDependencies. Rung 5 adds only the reader's build tools [@sveltejs/adapter-static, @sveltejs/kit,
@sveltejs/vite-plugin-svelte, svelte, svelte-check, vite], as devDependencies of apps/reader, and the root
may add only [typescript, @types/node, vitest, @amiceli/vitest-cucumber, fast-check, @stryker-mutator/core,
@stryker-mutator/vitest-runner, playwright]. Packages depend on each other as "workspace:*". "tailwindcss"
arrives in the Summit: upstream's reader uses it, and the ladder's variants leave it out.
Lifting the fence is a person's decision: see AGENTS.md, "Ask a human first".
~~~

Ask a coding agent to "make the cards look nicer" without the fence and this is the first thing many will
reach for. In Lean terms it is overproduction: nobody pulled it.

## Check yourself

- **(Analyse)** Your `LoPager` (the assignment) will read `currentCourse`. Which layers may it live in?
  Which may it not, and which message would tell you?
- **(Evaluate)** The Raw HTML rule is L4, a test with a teaching message. Svelte's own escaping is L5.
  Could "only one file may use `{@html}`" be made L5? What would you lose?

Make sure `git status` is clean: all three breaks undone.
