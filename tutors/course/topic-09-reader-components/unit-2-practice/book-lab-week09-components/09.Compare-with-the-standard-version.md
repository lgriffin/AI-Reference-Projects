# Compare with the standard version (Evaluate)

Rung 5's completed code ships as a zip, the **standard version**: the agreed baseline the whole class takes
into rung 6. It is in this week's practice unit, "Rung 5 (reader): the standard version". Do this step after the
assignment if you can, so that you have the most work of your own to compare.

## Download, unzip, run

Unzip it into a folder of its own, so that it does not overwrite your work:

~~~bash
mkdir -p ~/ladder/standard && cd ~/ladder/standard
unzip -q ~/Downloads/rung-5-reader.zip
ls tutors-ladder
cd tutors-ladder/rung-5-reader
pnpm install
pnpm test
~~~

The standard version passes its own gate, with the assignment's six tests skipped. Run its browser tier
too (`pnpm test:e2e`: `3 passed`).

## Compare

~~~bash
diff -rq --exclude=node_modules --exclude=.git --exclude=.svelte-kit --exclude=build --exclude=reports --exclude=static \
  ~/ladder/standard/tutors-ladder/rung-5-reader ~/ladder/rung5/tutors-ladder/rung-5-reader
~~~

For each difference, write one line. Is it:

- a **feature somebody pulled** (name the requirement: R-022, R-023, the reading-order rule);
- an **improvement** from a Kaizen step;
- or **drift** you did not mean?

Anything in the last group, put back. Then check the specification the same way:

~~~bash
diff ~/ladder/standard/tutors-ladder/rung-5-reader/REQUIREMENTS.md ~/ladder/rung5/tutors-ladder/rung-5-reader/REQUIREMENTS.md
~~~

You should see only added rows. If a row from R-001 to R-021 changed, you changed a requirement: that is on
`AGENTS.md`'s "Ask a human first" list, and the human is you. Decide on purpose.

## Judge your rung 5

- Does your copy pass `pnpm test`, `pnpm test:e2e`, `pnpm test:assignment` and
  `pnpm check:mutation-floors`?
- Every file under `apps/reader/src` that you added: can you name the requirement that pulled it?
- Which of the exit criteria on this week's topic page do you meet? Which not yet?
